# 31. 抽獎面板

管理員可透過指令在頻道中發送一個抽獎面板，讓使用者透過按鈕查看抽獎券資訊或購買抽獎券。

---

### 管理員：設置抽獎面板

在任意頻道中輸入以下指令：

```
!lottery_setup
```

也可以自訂兩個按鈕的文字：

```
!lottery_setup 獎池一覽 立即抽獎
```

- 第一個參數為**列表按鈕**的文字（預設「抽獎券列表」）。
- 第二個參數為**購買按鈕**的文字（預設「購買抽獎券」）。
- 不帶參數則使用預設值。

---

### 面板功能

面板包含兩個按鈕：

| 按鈕 | 功能 | 說明 |
|------|------|------|
| **抽獎券列表** | 查看所有抽獎券 | 顯示各抽獎券的費用、獎池內容及中獎機率 |
| **購買抽獎券** | 購買抽獎券進行抽獎 | 選擇抽獎券 → 輸入次數 → 扣點 → 立即抽獎 |

---

### 使用者操作

#### 查看抽獎券列表

1. 點擊「**抽獎券列表**」按鈕。
2. 系統顯示一則**僅您可見**的訊息，列出所有可用的抽獎券，包含：
   - 抽獎券名稱與每次消耗點數
   - 單次最大抽數限制
   - 獎池中各獎品的名稱與中獎機率
3. 該訊息會在 **15 秒後自動消失**。

#### 購買抽獎券（立即抽獎）

1. 點擊「**購買抽獎券**」按鈕。
2. 系統顯示**僅您可見**的購買介面，包含您目前的點數餘額。
3. 操作步驟：
   - **選擇抽獎券**：從下拉選單中選擇想要的抽獎券。
   - **點擊「確認購買」**：彈出輸入框，輸入抽獎次數。
   - **提交次數**：系統扣除點數，立即進行抽獎。

4. **抽獎結果：**
   - **單抽（1 次）**：顯示抽到的獎品，並提供兩個選擇按鈕：
     - 「**送給別人**」→ 選擇贈送對象，直接送出
     - 「**自己留著**」→ 存入您的禮物庫存
     - 如果 60 秒內未選擇，**自動存入庫存**
   - **多抽（2 次以上）**：顯示所有抽獎結果清單，**全部自動存入您的禮物庫存**

---

### 抽獎紀錄

所有抽獎紀錄都會保存在 Odoo 後台，管理員可在「Discord > 點數 > 抽獎紀錄」中查看。

**路徑：** Discord > 點數 > 抽獎紀錄

紀錄包含：
- 抽獎者
- 抽獎活動名稱
- 抽到的獎品
- 消耗的點數
- 抽獎時間

---

### 相關訊息模板

| 模板類型 | 用途 | 說明 |
|----------|------|------|
| **抽獎面板** | 面板本身的 Embed 訊息 | 面板類型，只能有一筆啟用 |
| **抽獎券列表** | 抽獎券列表查詢結果 | 顯示各抽獎券的獎池與機率 |
| **購買抽獎券提示** | 購買介面的提示訊息 | 支援 `{{ points }}` 變數顯示剩餘點數 |
| **抽獎公告** | 公告頻道的通知 | 顯示抽獎者、活動名稱、中獎結果 |

---

### 相關設定

在 Odoo 後台的 Discord 設定中：

| 設定 | 說明 |
|------|------|
| **抽獎面板允許身分組** | 允許使用 `!lottery_setup` 指令的 Discord Role ID |
| **抽獎公告頻道 ID** | 抽獎時發送公告的 Discord 頻道 ID |

---

### 注意事項

- `!lottery_setup` 指令僅限被授權的身分組成員使用。
- 指令訊息會在面板發送後**自動刪除**。
- 面板按鈕在**機器人重啟後仍然有效**。
- 使用者必須先完成帳號綁定才能使用。
- 購買抽獎券後**立即抽獎**，無法存放抽獎券。
- 抽到的禮物為「自有」來源，可以贈送給別人。
