# 24. 工單付款（Discord 操作）

管理員可在工單頻道中向客戶發起收款，客戶透過連結選擇付款方式完成付款。

---

### 建立付款單

管理員在工單頻道中輸入：

```
!pay 金額
```

**範例：**
```
!pay 1000
```

系統會在頻道中發送一則訊息，**@客戶** 並附上付款連結。管理員的指令訊息會自動刪除。

### 重複收款

如果需要修改金額或重新收款，直接再次執行 `!pay`：

```
!pay 2000
```

系統會自動**取消上一筆待付款的付款單**，並**刪除上一則付款連結訊息**，然後建立新的付款單。

### 付款流程

1. 客戶點擊訊息中的付款連結。
2. 開啟付款頁面，顯示工單編號、付款單編號和金額。
3. 客戶選擇付款方式：

| 付款方式 | 說明 |
|----------|------|
| **綠界支付** | 自動跳轉至綠界付款頁面，完成後自動確認 |
| **歐富寶支付** | 自動跳轉至歐富寶付款頁面，完成後自動確認 |
| **PayPal 支付** | 自動跳轉至 PayPal 付款頁面，使用 PayPal 帳號或信用卡付款，完成後自動確認 |
| **銀行匯款** | 顯示銀行帳號資訊，客戶匯款後點擊「我已完成匯款」通知管理員 |

### 付款成功

當綠界、歐富寶或 PayPal 付款成功時：

- 系統自動在工單頻道發送**付款成功通知**，@客戶和通知身分組，並**自動釘選**。
- 原本的付款連結訊息會被**自動刪除**。

### 付款失敗

如果付款過程中發生錯誤（例如交易被拒絕、餘額不足等）：

- 付款結果頁面會顯示「**付款失敗**」。
- 該付款單將**無法再使用**，付款連結會顯示「此付款單已無法使用」。
- 管理員需透過 `!pay` **重新建立新的付款單**給客戶。
- 管理員可在 Odoo 後台查看付款失敗的原因。

### 銀行匯款

銀行匯款的確認流程：

1. 客戶在付款頁面選擇「銀行匯款」，查看匯款資訊（銀行名稱、帳號、戶名）。
2. 客戶完成匯款後，點擊頁面上的「**我已完成匯款**」按鈕。
3. 系統自動在工單頻道發送通知，**@通知身分組**，並附上「**確認到帳**」按鈕。
4. 擁有通知身分組的成員點擊「**確認到帳**」按鈕，系統即確認付款完成。
5. 付款確認後，系統自動在工單頻道發送**付款成功通知**（自動釘選），並刪除原付款連結訊息。

> 管理員也可以在 Odoo 後台手動確認付款，詳見 [23. 工單付款管理](23-ticket-payment-setup.md)。

### 使用限制

- `!pay` 指令只能在**工單頻道**內使用（頻道必須對應一筆開啟中的工單）。
- 只有擁有**付款指令允許身分組**的成員才能使用（需在 Odoo 後台設定）。
- 金額必須為大於 0 的正整數。

### 注意事項

- 付款連結只能使用一次。付款完成、失敗或取消後，連結會顯示對應的狀態頁面。
- 同一工單可以多次使用 `!pay` 收取不同金額的款項。
- 工單關閉後，未完成的付款單仍可透過已發送的連結完成付款。
- 付款設定請參考 [23. 工單付款管理](23-ticket-payment-setup.md)。
