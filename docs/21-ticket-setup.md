# 21. 工單設定（後台）

管理工單系統的相關設定與工單記錄。

---

## 21.1 工單設定

### 進入方式

**路徑：** 設定 > 一般設定 > 往下捲動至「Discord」區塊 > 工單設定

### 設定欄位

| 欄位 | 說明 | 預設值 |
|------|------|--------|
| **允許身分組 ID** | 允許使用 `!ticket_setup` 指令的 Discord Role ID，多個以半形逗號分隔 | （空，未設定時無人可使用） |
| **支援身分組 ID** | 建立工單時自動加入頻道權限的 Discord Role ID，多個以半形逗號分隔 | （空） |
| **頻道前綴** | 工單頻道的名稱前綴 | `ticket` |
| **建立按鈕文字** | 面板上「建立工單」按鈕的顯示文字 | `建立工單` |

**格式範例（身分組 ID）：**
```
123456789012345678,987654321098765432
```

### 欄位說明

**允許身分組 ID：** 控制誰可以在 Discord 中輸入 `!ticket_setup` 指令來發送工單面板。只有擁有這些身分組的成員才能使用此指令。

**支援身分組 ID：** 當使用者建立工單時，系統會自動讓這些身分組的成員也能看到並回覆該工單頻道。通常設定為客服或管理員身分組。

**頻道前綴：** 工單頻道的命名格式為 `{前綴}-{流水號}`，例如 `ticket-0001`、`ticket-0002`。

**建立按鈕文字：** 可自訂面板上按鈕的顯示文字。修改後需重新執行 `!ticket_setup` 才會在新面板上生效。

## 21.2 工單管理

### 進入方式

**路徑：** Discord > 工單 > 工單管理

### 列表欄位

| 欄位 | 說明 |
|------|------|
| **工單編號** | 系統自動產生的流水號（格式：0001、0002...） |
| **客戶** | 建立工單的 Odoo 聯絡人（透過 Discord 帳號綁定） |
| **頻道 ID** | 對應的 Discord 頻道 ID |
| **狀態** | 開啟 / 已關閉 |
| **建立時間** | 工單建立的時間 |
| **關閉時間** | 工單關閉的時間 |

### 工單狀態說明

| 狀態 | 標示顏色 | 說明 |
|------|----------|------|
| **開啟** | 綠色 | 工單進行中，頻道仍存在 |
| **已關閉** | 灰色 | 工單已關閉，頻道已刪除 |

### 篩選與分組

**快速篩選：**
- 開啟中（預設）/ 已關閉

**分組檢視：**
- 依狀態分組
- 依客戶分組

### 注意事項

- 工單為**唯讀**，無法在後台手動新增或刪除。
- 工單狀態由 Discord 端操作自動更新。
- 點擊客戶欄位可跳轉至對應的聯絡人頁面。
- 工單有 Chatter 功能，狀態變更會自動記錄。

## 21.3 訊息模板

工單系統使用兩個模板類型，可在「訊息模板」中自訂：

| 模板類型 | 觸發時機 | 可用變數 |
|----------|----------|----------|
| **工單面板** | 執行 `!ticket_setup` 時發送到頻道 | （無） |
| **工單歡迎訊息** | 工單建立後發送到新頻道 | `{{ user }}`（@ mention）、`{{ username }}`（名稱）、`{{ ticket_name }}`（頻道名稱） |

> 模板編輯路徑：Discord > 設定 > 訊息模板
