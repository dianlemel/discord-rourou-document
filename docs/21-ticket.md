# 22. 工單系統（Discord 操作）

使用者可透過面板按鈕建立專屬的客服頻道，與支援人員一對一溝通。

---

### 建立工單

1. 管理員在任意頻道中執行 `!ticket_setup`（不限頻道），頻道內會出現一則面板訊息和「**建立**」按鈕。也可以自訂按鈕文字，例如 `!ticket_setup 開啟工單`。
2. 使用者點擊按鈕後，系統會在**同一類別**下自動建立一個新的文字頻道（例如 `ticket-0001`）。
3. 使用者會收到一則 ephemeral 訊息（僅自己可見），提示已建立並附上頻道連結，該訊息會在 **10 秒後自動消失**。
4. 在新頻道中，系統會發送歡迎訊息，並**自動釘選**。

### 工單頻道權限

建立的頻道有以下權限設定：

| 對象 | 權限 |
|------|------|
| **@everyone** | 無法查看 |
| **建立者** | 可讀取、發送訊息、查看歷史訊息 |
| **支援身分組** | 可讀取、發送訊息、查看歷史訊息 |
| **機器人** | 可讀取、發送訊息、管理頻道 |

> 只有建立者和支援人員能看到頻道，其他成員無法查看。

### 關閉工單

1. 在頻道中，點擊歡迎訊息下方的「**關閉**」按鈕。
2. 系統會發送一則 ephemeral 確認訊息，提供「**確認關閉**」和「**取消**」兩個按鈕。
3. 點擊「確認關閉」後，頻道會被**刪除**，Odoo 中的記錄會自動更新為「已關閉」。
4. 點擊「取消」則不做任何操作。

> 後台人員也可以直接在 Odoo 後台修改狀態來關閉，效果相同（頻道會被刪除）。詳見 [21. 工單設定](21-ticket-setup.md)。

### 自動綁定

如果使用者在點擊「建立」按鈕時尚未綁定帳號，系統會**自動建立聯絡人**（同 `!bind` 的效果），無需額外操作。

### 工單付款

管理員可在工單頻道中使用 `!pay` 指令向客戶收款。詳細說明請參考 [24. 工單付款](24-ticket-payment.md)。

### 頻道刪除自動關閉

若工單頻道被管理員在 Discord 中手動刪除，系統會**自動偵測**並關閉對應的工單，Odoo 中的記錄會自動更新為「已關閉」。

### 注意事項

- `!ticket_setup` 指令僅限被授權的身分組成員使用（需在 Odoo 後台設定）。
- 指令訊息會在面板發送後**自動刪除**，頻道中只會留下面板訊息。
- 面板上的按鈕在**機器人重啟後仍然有效**，不需要重新設定。
- 頻道關閉後無法恢復，請確保問題已解決再關閉。
- 若頻道被手動刪除，系統會自動關閉工單，不會產生孤立記錄。
- 支援身分組的設定請參考 [21. 工單設定](21-ticket-setup.md)。
