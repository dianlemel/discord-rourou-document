# 15. 贈送禮物

使用點數向其他已綁定的使用者贈送禮物。

### 使用方式

```
!gift @對方 <禮物名稱>
!gift @對方 <禮物名稱> <數量>
```

**範例：**

```
!gift @John 玫瑰
!gift @John 玫瑰 3
```

### 說明

- 每種禮物有固定的點數消耗，贈送時會從您的點數中扣除（**禮物單價 × 數量**）。
- 禮物名稱可以使用主名稱或任一別名。
- 數量為選填，**預設為 1**。
- 贈送成功後，機器人會透過**私訊**通知您贈送結果及剩餘點數。
- 如果伺服器有設定贈送公告頻道，贈送紀錄會在該頻道公開顯示，包含禮物的圖片和敘述。

### 消耗計算

```
消耗點數 = 禮物單價 × 數量
```

**範例：** 玫瑰花單價為 50 點，贈送 3 朵 → 消耗 150 點。

### 其他贈送方式

除了文字指令外，還可以透過禮物面板操作：

- **購買禮物 → 立即贈送**：在禮物面板點擊「購買禮物」，購買後選擇「立即贈送」。
- **從庫存贈送**：如果您有自有庫存中的禮物（購買或抽獎獲得），可以在禮物面板點擊「贈送禮物」，從庫存中選擇禮物送出（不需扣點）。

### 注意事項

- **雙方都必須已完成帳號綁定**，否則無法贈送。
- 您的點數餘額必須**大於或等於**總消耗點數。
- **不能贈送給自己**。
- 數量必須為**正整數**。
- 贈送只會**扣除贈送者的點數**，接收者不會收到點數，而是收到禮物。
- 接收者收到的禮物為「收到」來源，**不可再轉送**。
- 贈送一旦完成即**無法撤回**，請確認對象和數量後再操作。
- 如果找不到禮物名稱，機器人會提示「找不到禮物」。
