# 1. 基本設定

### 進入方式

**路徑：** 設定 > 一般設定 > 往下捲動至「Discord」區塊

### 1.1 Bot Token

| 欄位 | 說明 |
|------|------|
| **Bot Token** | Discord 機器人的身份驗證令牌（密碼欄位，輸入後不會明文顯示） |

**如何取得 Bot Token：**

1. 前往 [Discord Developer Portal](https://discord.com/developers/applications)。
2. 點擊「New Application」建立應用程式。
3. 左側選單進入「Bot」頁面。
4. 點擊「Reset Token」取得 Token，並複製貼入此欄位。
5. 在「Bot」頁面下方，開啟以下 **Privileged Gateway Intents**：
   - `MESSAGE CONTENT INTENT`（讀取訊息內容）
   - `SERVER MEMBERS INTENT`（讀取成員列表，群發通知需要）

> **重要：** Token 僅會顯示一次，請妥善保存。如果遺失需重新產生。

### 1.2 重啟 Bot

設定頁面上有一個「**重啟 Bot**」按鈕，當修改了 Token 或需要手動重啟機器人時，點擊此按鈕即可。

> 一般情況下，修改設定後系統會自動同步，**不需要手動重啟**。

### 1.3 點數單價

| 欄位 | 說明 | 預設值 |
|------|------|--------|
| **點數單價** | 每點的售價（單位：元） | 10 |

此設定影響用戶購買點數時的付款金額計算：

```
付款金額 = 購買點數 × 點數單價
```

**範例：** 單價設為 10 元，用戶購買 100 點 → 付款金額為 NT$ 1,000。

### 1.4 贈送公告頻道

| 欄位 | 說明 |
|------|------|
| **公告頻道 ID** | 當用戶贈送禮物時，系統會在此頻道發送公告訊息 |

**如何取得 Discord 頻道 ID：**

1. 在 Discord 中開啟「使用者設定 > 進階 > 開發者模式」。
2. 對目標頻道**按右鍵** > 選擇「複製頻道 ID」。
3. 將 ID 貼入此欄位。

> 如果不填寫，贈送時將不會發送公告。

### 1.5 群發通知 — 允許身分組 ID

| 欄位 | 說明 |
|------|------|
| **允許身分組 ID** | 允許使用 `!announce` 指令的 Discord 身分組 ID，多個以**半形逗號**分隔 |

**格式範例：**
```
123456789012345678,987654321098765432
```

**如何取得身分組 ID：**

1. 確認已開啟 Discord 開發者模式。
2. 進入「伺服器設定 > 身分組」。
3. 對目標身分組**按右鍵** > 選擇「複製身分組 ID」。

> 只有擁有這些身分組的成員才能使用群發通知指令。

### 1.6 工單設定

| 欄位 | 說明 |
|------|------|
| **允許身分組 ID** | 允許使用 `!ticket_setup` 指令的 Discord Role ID，多個以半形逗號分隔 |
| **支援身分組 ID** | 建立工單時自動加入頻道權限的 Discord Role ID，多個以半形逗號分隔 |
| **頻道前綴** | 工單頻道名稱前綴（預設 `ticket`），命名格式為 `{前綴}-{流水號}` |
| **建立按鈕文字** | 面板上建立按鈕的顯示文字（預設「建立工單」） |

> 詳細說明請參考 [21. 工單設定與管理](21-ticket-setup.md)。
