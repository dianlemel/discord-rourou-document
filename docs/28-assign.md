# 工單派工（Discord 操作）

管理員可在工單頻道中使用 `!assign` 指令，為工單指派工人並建立專屬的溝通頻道。

---

### 派工指令

管理員在工單頻道中輸入：

```
!assign @使用者 頻道名稱
```

**範例：**
```
!assign @John 網站設計
```

### 派工流程

1. 管理員在工單頻道（頻道A）中輸入 `!assign @工人 頻道名稱`。
2. 系統在指定類別下建立新的文字頻道（頻道B），名稱為指定的頻道名稱。
3. 頻道A 發送一則**派工通知**（Embed 格式），通知工單客戶已建立工作頻道，並**自動釘選**。
4. 頻道B 發送**歡迎訊息**（Embed 格式），顯示老闆和工人資訊，並附上「**刪除頻道**」按鈕。
5. 管理員的指令訊息會**自動刪除**。

### 派工頻道權限

建立的派工頻道有以下權限設定：

| 對象 | 權限 |
|------|------|
| **@everyone** | 無法查看 |
| **工單客戶（老闆）** | 可讀取、發送訊息、查看歷史訊息 |
| **被指派的工人** | 可讀取、發送訊息、查看歷史訊息 |
| **額外身分組** | 可讀取、發送訊息、查看歷史訊息 |
| **機器人** | 可讀取、發送訊息、管理頻道 |

> 只有工單客戶、工人和指定身分組能看到頻道，其他成員無法查看。

### 多次派工

同一張工單可以多次使用 `!assign` 指令，建立多個派工頻道。每次派工都會建立獨立的頻道和記錄。

### 刪除派工頻道

**方法一：使用按鈕刪除**

1. 在派工頻道中，點擊歡迎訊息下方的「**刪除頻道**」按鈕。
2. 只有擁有**允許身分組**的成員才能使用此按鈕，其他人點擊會顯示「無權限」（10 秒後自動消失）。
3. 有權限者點擊後，系統會發送確認訊息，提供「**確認刪除**」和「**取消**」按鈕（10 秒內未操作會自動消失）。
4. 點擊「確認刪除」後：
   - 派工頻道（頻道B）會被**刪除**
   - 工單頻道（頻道A）中的**派工通知訊息也會一併刪除**
   - Odoo 中的記錄會自動更新為「已關閉」並記錄關閉時間

**方法二：手動刪除頻道**

管理員也可以在 Discord 中直接手動刪除派工頻道，效果相同：
- Odoo 中的記錄會自動更新為「已關閉」
- 工單頻道中的派工通知訊息會一併刪除

### 使用限制

- `!assign` 指令只能在**工單頻道**內使用（頻道必須對應一筆開啟中的工單）。在非工單頻道中使用會被忽略。
- 只有擁有**允許身分組**的成員才能使用（需在 Odoo 後台設定）。
- 必須指定一位 @使用者 和頻道名稱，缺少任一項會提示錯誤（10 秒後自動消失）。
- 必須在後台設定**頻道類別 ID**，否則無法建立派工頻道。

### 注意事項

- 派工按鈕在**機器人重啟後仍然有效**，不需要重新設定。
- 頻道刪除後無法恢復，請確保溝通已完成再刪除。
- 若派工頻道被手動刪除，系統會自動關閉派工記錄，不會產生孤立記錄。
- 派工設定請參考 [派工設定與管理](27-assign-setup.md)。
