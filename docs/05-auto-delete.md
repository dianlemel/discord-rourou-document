# 5. 自動刪除頻道

設定指定頻道的訊息在發送後自動刪除，適合用於指令頻道，保持頻道整潔。

### 進入方式

**路徑：** Discord > 設定 > 自動刪除頻道

### 欄位說明

| 欄位 | 說明 | 預設值 |
|------|------|--------|
| **頻道 ID** | Discord 頻道的數字 ID | （必填） |
| **頻道名稱** | 方便辨識用的名稱 | （選填） |
| **刪除延遲（秒）** | 訊息發送後幾秒刪除 | 5 |
| **刪除管理員訊息** | 是否刪除具有管理員權限的成員的訊息 | 否 |
| **刪除機器人訊息** | 是否刪除機器人發送的訊息 | 否 |
| **刪除一般使用者訊息** | 是否刪除一般使用者的訊息 | 是 |
| **啟用** | 是否啟用此規則 | 是 |

### 設定範例

**場景一：指令頻道（只保留管理員和機器人的訊息）**

| 欄位 | 值 |
|------|-----|
| 頻道 ID | 1234567890 |
| 頻道名稱 | #指令區 |
| 刪除延遲 | 5 秒 |
| 刪除管理員訊息 | 否 |
| 刪除機器人訊息 | 否 |
| 刪除一般使用者訊息 | 是 |

**場景二：臨時訊息頻道（所有訊息都刪除）**

| 欄位 | 值 |
|------|-----|
| 頻道 ID | 9876543210 |
| 頻道名稱 | #臨時對話 |
| 刪除延遲 | 10 秒 |
| 刪除管理員訊息 | 是 |
| 刪除機器人訊息 | 是 |
| 刪除一般使用者訊息 | 是 |

### 注意事項

- 每個頻道只能設定**一筆**自動刪除規則。
- 自動刪除**不影響指令的執行**，機器人會在刪除前讀取並處理指令，回覆則透過私訊發送。
- 如需暫時停用，取消勾選「啟用」即可，不必刪除整筆設定。
- 修改後**立即生效**。
