# 30. 抽獎管理

管理抽獎活動，每個抽獎活動有獨立的獎池和點數消耗。

### 進入方式

**路徑：** Discord > 點數 > 抽獎管理

### 基本欄位

| 欄位 | 說明 | 必填 |
|------|------|------|
| **名稱** | 抽獎活動的顯示名稱 | 是 |
| **點數消耗** | 每次抽獎所需點數 | 是 |
| **敘述** | 抽獎活動的文字說明 | 否 |
| **單次最大抽數** | 使用者單次最多可抽幾次（0 = 不限，預設不限） | 否 |
| **啟用** | 是否啟用此抽獎活動 | — |

### 獎池明細

每個抽獎活動可設定多個獎品，每個獎品有對應的**權重**。

| 欄位 | 說明 |
|------|------|
| **獎品** | 關聯一個禮物項目（來自禮物管理） |
| **權重** | 權重越大，中獎機率越高 |

**機率計算方式：**

```
某獎品的中獎機率 = 該獎品權重 / 所有獎品權重總和
```

**範例：**

| 獎品 | 權重 | 機率 |
|------|------|------|
| 普通禮物 | 70 | 70% |
| 稀有禮物 | 25 | 25% |
| 傳說禮物 | 5 | 5% |

### 抽獎流程

1. 使用者在 Discord 的抽獎面板選擇抽獎券並輸入抽獎次數。
2. 系統扣除對應的點數（點數消耗 × 次數）。
3. 根據獎池權重隨機抽取獎品。
4. 抽到的禮物存入使用者的**自有庫存**（可以之後贈送給別人）。
5. 單抽時可選擇「送給別人」或「自己留著」。
6. 多抽時全部直接存入庫存。

### 注意事項

- 停用的抽獎活動不會在 Discord 面板中顯示。
- 獎池中只會顯示**啟用中**的禮物項目。
- 權重必須大於 0。
- 抽到的禮物屬於「自有」來源，可以贈送給其他人；對方收到後變為「收到」來源，不可再轉送。
- 修改後**立即生效**。
