# 18. 常見問題 FAQ

### Q：我輸入指令後沒有任何反應？

**可能原因：**

- **尚未綁定帳號** — 請先使用 `!bind` 完成綁定。
- **在錯誤的頻道** — 部分指令可能限制只能在特定頻道使用，請確認您在正確的頻道（管理員可在 Odoo 後台的「頻道設定」中查看）。
- **指令已被停用** — 管理員可能暫時停用了該指令（可在「指令設定」中確認）。
- **指令格式錯誤** — 請確認指令格式正確，例如 `!gift` 後面必須接 @對方 和禮物名稱。
- **指令名稱已變更** — 管理員可能自訂了不同的指令名稱。

### Q：我收不到機器人的私訊？

**解決方式：**

1. 開啟 Discord **使用者設定**。
2. 進入「隱私與安全」。
3. 開啟「允許來自伺服器成員的私人訊息」。

### Q：付款成功但點數沒有到帳？

- 通常點數會在付款完成後**立即到帳**。
- 如果超過數分鐘仍未收到，管理員可至 Odoo 後台「購買訂單」中查看該筆訂單的狀態。
- 如為「待付款」狀態，可能是金流回調尚未完成，請確認金流設定是否正確。

### Q：我可以將點數轉回現金嗎？

- 點數**無法**兌換為現金或退款，購買前請確認需求。

### Q：贈送禮物後點數去了哪裡？

- 贈送禮物時，點數會從您的帳戶中**扣除**，但**不會轉移給接收者**。點數是購買禮物的消耗，接收者收到的是禮物本身。

### Q：贈送錯對象了怎麼辦？

- 禮物贈送一旦完成即**無法撤回**。管理員可在 Odoo 後台手動調整點數餘額。

### Q：找不到禮物名稱？

- 確認禮物名稱是否正確，可嘗試使用禮物的別名。
- 管理員可能尚未在後台新增該禮物，或該禮物已被停用。

### Q：贈送公告的圖片沒有顯示？

- 確認禮物項目有上傳圖片。
- 確認 Odoo 的 `web.base.url` 系統參數設定為外部可存取的網址（例如 `https://your-domain.com`），而非 `http://localhost:8069`。

### Q：Bot 沒有上線或無回應？

**管理員排查步驟：**

1. 確認 Odoo 設定中的 **Bot Token** 是否正確填寫。
2. 確認 Discord Developer Portal 中已開啟必要的 **Intents**（MESSAGE CONTENT、SERVER MEMBERS）。
3. 嘗試在 Odoo 設定頁面點擊「**重啟 Bot**」按鈕。
4. 檢查 Odoo 伺服器的日誌是否有錯誤訊息。

### Q：付款頁面顯示錯誤或無法選擇付款方式？

**管理員排查步驟：**

1. 確認至少一種金流（綠界或歐富寶）的**商店代號、HashKey、HashIV** 都已正確填寫。
2. 確認**測試模式**的設定與實際環境一致（正式環境請取消勾選）。
3. 確認 Odoo 的 `web.base.url` 系統參數設定正確（付款回調需要用到）。

### Q：點選會員中心面板按鈕，跳到 Discord 卻顯示「無效的 OAuth2 redirect_uri」？

**常見原因**：Odoo 的 `web.base.url` 與 Discord Developer Portal 的 Redirect URI 不一致（最常見是 `http` vs `https`）。

**解法**：

1. 開啟開發者模式 → **設定 > 技術 > 系統參數**。
2. 確認 `web.base.url` 是 `https://你的網域`（與 Developer Portal 設定的 Redirect URI 完全一致）。
3. 確認 `web.base.url.freeze` 設為 `True`，避免 Odoo 自動把 `web.base.url` 覆寫回 http。

詳細說明請參考 [17. 會員中心設定](32-portal-setup.md)。

### Q：登入會員中心後，右上角的頭像顯示不出來？

**常見原因**：可能您是先用 `!bind` 綁定，當時沒成功下載頭像；或先用會員中心 OAuth2 自動建立帳號，當時 Discord CDN 暫時無法存取。

**解法**：

- 透過 OAuth2 建立的帳號會在登入時嘗試下載頭像，如果失敗您可以請管理員在 Odoo 後台 → 聯絡人中手動上傳。
- 不影響其他功能使用。

### Q：會員中心一直跳回登入頁？

**常見原因**：

- 瀏覽器禁用了 cookie。
- 使用無痕模式且關閉了視窗（cookie 被清除）。
- 您之前的 session 已超過 7 天有效期。

**解法**：確認瀏覽器允許接收 cookie，重新點選「使用 Discord 登入」即可。
