# 7. 禮物管理

管理可供贈送的禮物項目，每種禮物有固定點數消耗，支援別名查找和自訂 Embed 樣式。

### 進入方式

**路徑：** Discord > 點數 > 禮物管理

### 基本欄位

| 欄位 | 說明 | 必填 |
|------|------|------|
| **名稱** | 禮物的主要顯示名稱 | 是 |
| **點數消耗** | 贈送一個此禮物所需的點數 | 是 |
| **敘述** | 禮物的文字說明 | 否 |
| **啟用** | 是否啟用此禮物 | — |

### 圖片欄位

| 欄位 | 說明 |
|------|------|
| **圖片** | 上傳禮物圖片（支援 PNG、JPG、GIF），會顯示在贈送公告的 Embed 大圖 |
| **縮圖** | 上傳禮物縮圖（支援 PNG、JPG、GIF），會顯示在贈送公告的 Embed 右上角 |

### Embed 樣式欄位（選填）

這些欄位用於覆蓋贈送公告模板的預設 Embed 樣式，讓不同禮物可以有不同的公告外觀。**留空則使用模板預設值。**

| 欄位 | 說明 | 範例 |
|------|------|------|
| **Embed 標題** | 覆蓋公告的 Embed 標題 | `🌹 玫瑰花` |
| **Embed 顏色** | 覆蓋公告的 Embed 色條顏色（Hex 色碼） | `#FF0000` |
| **頁尾文字** | 覆蓋公告的 Embed 頁尾 | `愛的表達` |

### 別名

每個禮物可以設定多個**別名**，使用者在 Discord 中可以用主名稱或任一別名來贈送禮物。

**範例：** 禮物「玫瑰花」設定別名「玫瑰」和「rose」，則以下指令效果相同：
```
!gift @John 玫瑰花
!gift @John 玫瑰
!gift @John rose
```

### 名稱唯一性規則

- 禮物主名稱不能與其他禮物的主名稱或別名重複。
- 別名不能與任何禮物的主名稱重複。
- 別名在全系統中必須唯一。

### 禮物的取得方式

使用者可以透過以下方式取得禮物：

| 方式 | 說明 | 庫存來源 |
|------|------|----------|
| **被贈送** | 其他使用者透過 `!gift` 或面板贈送 | 收到（不可轉送） |
| **購買禮物** | 在禮物面板花點數購買 | 自有（可贈送） |
| **抽獎中獎** | 在抽獎面板抽獎獲得 | 自有（可贈送） |

### 注意事項

- 停用的禮物無法被贈送或購買，使用者嘗試時會收到「找不到禮物」的提示。
- 停用的禮物也不會出現在抽獎獎池中。
- 圖片需確保 Odoo 的 `web.base.url` 設定為外部可存取的網址，Discord 才能正確顯示圖片。
- 修改後**立即生效**。
