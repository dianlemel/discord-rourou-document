# 2. 金流設定

系統支援四種付款方式，可以個別啟用或停用，也可以同時啟用多種。

### 進入方式

**路徑：** 設定 > 一般設定 > 往下捲動至「Discord」區塊 > 綠界科技 / 歐富寶 / PayPal / 銀行付款

---

## 付款方式開關

每種付款方式都有獨立的**啟用開關**，可以控制是否在付款頁面顯示該選項。

### 2.1 綠界科技（ECPay）

| 欄位 | 說明 |
|------|------|
| **啟用綠界支付** | ✅ 勾選後才會在付款頁面顯示綠界支付選項 |
| **測試模式** | 勾選後使用綠界的**測試環境**（用於開發測試，不會真正扣款） |
| **商店代號** | 綠界分配的 MerchantID |
| **HashKey** | API 驗證密鑰（密碼欄位） |
| **HashIV** | API 驗證初始向量（密碼欄位） |

**申請方式：** 前往 [綠界科技官網](https://www.ecpay.com.tw/) 註冊商店帳號，取得以上資訊。

### 2.2 歐富寶（OPay）

| 欄位 | 說明 |
|------|------|
| **啟用歐富寶支付** | ✅ 勾選後才會在付款頁面顯示歐富寶支付選項 |
| **測試模式** | 勾選後使用歐富寶的**測試環境** |
| **商店代號** | 歐富寶分配的 MerchantID |
| **HashKey** | API 驗證密鑰（密碼欄位） |
| **HashIV** | API 驗證初始向量（密碼欄位） |

**申請方式：** 前往 [歐富寶官網](https://www.opay.tw/) 註冊商店帳號，取得以上資訊。

### 2.3 PayPal

| 欄位 | 說明 |
|------|------|
| **啟用 PayPal 支付** | ✅ 勾選後才會在付款頁面顯示 PayPal 支付選項 |
| **沙盒模式** | 勾選後使用 PayPal 的**沙盒測試環境**（用於開發測試，不會真正扣款） |
| **Client ID** | PayPal REST API 的 Client ID |
| **Client Secret** | PayPal REST API 的 Client Secret（密碼欄位） |

**申請方式：**

1. 前往 [PayPal Developer](https://developer.paypal.com/) 註冊開發者帳號
2. 進入 Dashboard > Apps & Credentials
3. 選擇 **Sandbox**（測試）或 **Live**（正式）模式
4. 點擊 **Create App** 建立應用程式
5. 取得 **Client ID** 和 **Secret**

**測試環境設定：**
- 在 PayPal Developer Dashboard 的 Sandbox > Accounts 中可以建立測試帳號
- 使用測試帳號進行付款測試，不會產生真實交易

**正式環境設定：**
- 切換到 Live 模式建立正式環境的 App
- 在 Odoo 中**取消勾選**沙盒模式，並填入正式環境的 Client ID 和 Secret

**PayPal 特色：**
- ✅ 支援國際付款，適合有海外客戶的需求
- ✅ 用戶可使用 PayPal 帳戶或信用卡付款
- ✅ 付款過程中可取消，返回重新選擇其他付款方式

### 2.4 銀行匯款（僅工單付款）

| 欄位 | 說明 |
|------|------|
| **啟用銀行匯款** | ✅ 勾選後才會在工單付款頁面顯示銀行匯款選項 |
| **銀行名稱** | 顯示給客戶的銀行名稱（例如：中國信託） |
| **銀行帳號** | 顯示給客戶的匯款帳號 |
| **匯款 QR Code** | 上傳 QR Code 圖片，方便客戶掃碼匯款 |

**注意：** 銀行匯款僅適用於**工單付款**，點數購買不支援此方式。

**匯款流程：**
1. 客戶選擇銀行匯款後，會看到銀行資訊和 QR Code
2. 客戶完成匯款後點擊「我已完成匯款」按鈕
3. 系統會在工單頻道通知管理員，並顯示「確認到帳」按鈕
4. 管理員確認後，系統自動標記為已付款

## 付款頁面體驗

### 即時載入效果
- 用戶點擊任何付款按鈕時，會立即顯示全螢幕載入動畫
- 消除等待時的停頓感，提升用戶體驗

### 取消付款
- **PayPal**：用戶在 PayPal 頁面點擊取消，會返回付款選項頁面，可重新選擇其他付款方式
- **綠界/歐富寶**：用戶可直接關閉頁面，訂單會保持待付款狀態

### 無付款方式提示
- 如果所有付款方式都未啟用，付款頁面會顯示：
  > ⚠️ 目前沒有可用的付款方式
  > 請聯繫管理員

---

## 注意事項

- **測試模式 / 沙盒模式** 僅供開發或測試時使用，正式上線前請務必**取消勾選**。
- HashKey、HashIV 和 Client Secret 為敏感資訊，系統以密碼形式儲存，輸入後不會明文顯示。
- **至少需要啟用一種付款方式**，否則用戶將無法完成付款。
- 可以根據需求隨時啟用或停用特定付款方式，不影響其他已啟用的方式。
- 修改設定後需要**儲存**才會生效。

## 常見設定組合

### 組合 1：僅台灣本地付款
- ✅ 啟用綠界支付
- ✅ 啟用歐富寶支付
- ❌ 停用 PayPal 支付

### 組合 2：支援國際付款
- ✅ 啟用綠界支付
- ✅ 啟用 PayPal 支付
- ❌ 停用歐富寶支付

### 組合 3：工單付款含銀行匯款
- ✅ 啟用綠界支付
- ✅ 啟用 PayPal 支付
- ✅ 啟用銀行匯款（僅工單付款可用）

### 組合 4：僅 PayPal
- ❌ 停用綠界支付
- ❌ 停用歐富寶支付
- ✅ 啟用 PayPal 支付
