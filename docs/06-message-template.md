# 6. 訊息模板

管理 Discord 機器人回覆使用者時的訊息內容與樣式，支援 Jinja2 模板語法和 Discord Embed 卡片格式。

### 進入方式

**路徑：** Discord > 設定 > 訊息模板

### 欄位說明

| 欄位 | 說明 |
|------|------|
| **名稱** | 模板的辨識名稱 |
| **模板類型** | 此模板用於哪個場景（見下方列表） |
| **啟用** | 是否啟用此模板 |
| **內容 (body)** | 訊息主體文字，支援 Jinja2 語法 |
| **使用 Embed** | 勾選後以 Discord Embed 卡片樣式顯示 |

### Embed 相關欄位（勾選「使用 Embed」後出現）

| 欄位 | 說明 | 範例 |
|------|------|------|
| **Embed 標題** | 卡片的標題文字，支援 Jinja2 | `💳 付款成功` |
| **Embed 色碼** | 卡片左側色條的顏色（Hex 色碼），支援 Jinja2 | `#FF5733` |
| **Embed 頁尾** | 卡片底部小字，支援 Jinja2 | `感謝您的購買！` |

### 圖片設定（勾選「使用 Embed」後出現）

每個模板的圖片和縮圖都支援兩種來源，**URL 覆蓋優先於上傳的檔案**：

| 欄位 | 說明 |
|------|------|
| **圖片** | 上傳圖片檔案（支援 PNG、JPG、GIF 等） |
| **URL 覆蓋（圖片）** | Jinja2 URL，設定時優先於上傳的圖片 |
| **縮圖** | 上傳縮圖檔案（支援 PNG、JPG、GIF 等） |
| **URL 覆蓋（縮圖）** | Jinja2 URL，設定時優先於上傳的縮圖 |

**圖片優先級：** URL 覆蓋（渲染後非空） > 上傳的檔案 > 不顯示

> 贈送公告模板使用 URL 覆蓋欄位（`{{ gift_image }}`、`{{ gift_thumbnail }}`）來動態顯示不同禮物的圖片。其他模板可以直接上傳靜態圖片。

### 模板類型一覽

| 模板類型 | 觸發時機 | 可用變數 |
|----------|----------|----------|
| **綁定面板** | 執行 `!bind_setup` 時發送到頻道 | （無） |
| **已綁定通知** | 用戶重複綁定（`!bind` 或面板按鈕） | `{{ points }}` — 目前點數 |
| **綁定成功通知** | 首次綁定成功（`!bind` 或面板按鈕） | （無） |
| **購買確認** | 用戶執行 `!buy` | `{{ points }}` — 購買點數 |
| **贈送公告** | 贈送禮物時發到公告頻道 | `{{ sender }}`、`{{ receiver }}`、`{{ gift_name }}`、`{{ gift_description }}`、`{{ gift_image }}`、`{{ gift_thumbnail }}`、`{{ gift_embed_title }}`、`{{ gift_embed_color }}`、`{{ gift_embed_footer }}`、`{{ quantity }}`、`{{ total_cost }}` |
| **贈送成功通知** | 贈送完成通知贈送者 | `{{ gift_name }}`、`{{ gift_description }}`、`{{ quantity }}`、`{{ total_cost }}`、`{{ receiver }}`、`{{ remaining_points }}` |
| **收到的禮物查詢** | 用戶執行 `!mygifts` | `{{ gifts }}` — 禮物列表（每項含 `name` 和 `quantity`） |
| **付款成功通知** | 付款完成後通知用戶 | `{{ order_no }}`、`{{ points }}`、`{{ amount }}`、`{{ points_before }}`、`{{ points_after }}` |
| **點數查詢** | 用戶執行 `!points` | `{{ points }}` — 目前點數 |
| **群發通知** | 群發的訊息內容 | `{{ message }}`、`{{ role_name }}`、`{{ sender }}`、`{{ guild_name }}` |
| **群發結果通知** | 群發完成後通知發送者 | `{{ role_name }}`、`{{ total }}`、`{{ success }}`、`{{ failed }}` |
| **禮物面板** | 執行 `!gift_setup` 時發送到頻道 | （無） |
| **贈送禮物提示** | 點擊禮物面板「贈送禮物」按鈕後的提示訊息 | `{{ points }}` — 目前點數 |
| **工單面板** | 執行 `!ticket_setup` 時發送到頻道 | （無） |
| **工單歡迎訊息** | 工單建立後發送到新頻道 | `{{ user }}`、`{{ username }}`、`{{ ticket_name }}` |
| **工單付款通知** | 管理員執行 `!pay` 時 @客戶的訊息 | `{{ customer }}`、`{{ amount }}`、`{{ payment_url }}`、`{{ ticket_name }}`、`{{ payment_no }}` |
| **工單付款成功通知** | 付款成功時在工單頻道的通知 | `{{ customer }}`、`{{ payment_no }}`、`{{ amount }}`、`{{ ticket_name }}`、`{{ payment_method }}` |

### Jinja2 語法快速入門

**插入變數：**
```
目前點數：{{ points }} 點
```

**條件判斷：**
```
{% if gift_description %}敘述：{{ gift_description }}{% endif %}
```

**預設值：**
```
{{ gift_embed_title or '🎁 禮物贈送' }}
```

**迴圈（用於禮物列表）：**
```
{% for gift in gifts %}🎁 {{ gift.name }} x{{ gift.quantity }}
{% endfor %}
```

**數字格式化（加千分位逗號）：**
```
金額：NT$ {{ "{:,}".format(amount) }}
```

### 隨機模板功能

同一模板類型可以建立**多個**模板，系統會從已啟用的模板中**隨機選擇**一個使用，讓回覆更有變化。

**範例：** 建立 3 個「綁定成功通知」模板，每次綁定成功時隨機顯示不同的歡迎訊息。

> **注意：** 面板類型（綁定面板、點數面板、禮物面板、工單面板）同時只能有**一筆啟用的模板**，建立第二筆時系統會提示錯誤。

### 注意事項

- 每個模板類型至少要有**一個啟用的模板**，否則機器人會無法回覆。
- 模板語法錯誤時，系統會回退顯示原始模板文字。
- Embed 色碼必須為有效的 Hex 格式（如 `#FF5733`）。
- 上傳的圖片支援 GIF 動圖。
- 修改後**立即生效**。
