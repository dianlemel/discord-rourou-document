# 3. 指令設定

管理 Discord 機器人可辨識的指令名稱，支援自訂指令名稱與別名。

### 進入方式

**路徑：** Discord > 設定 > 指令設定

### 欄位說明

| 欄位 | 說明 | 必填 |
|------|------|------|
| **指令名稱** | 使用者輸入的指令文字（不含 `!` 前綴） | 是 |
| **行為類型** | 此指令觸發的功能 | 是 |
| **說明** | 備註用途（不會顯示在 Discord 上） | 否 |
| **啟用** | 是否啟用此指令 | — |

### 行為類型

| 類型 | 說明 |
|------|------|
| 綁定帳號 (bind) | 執行帳號綁定 |
| 查詢點數 (points) | 查詢點數餘額 |
| 購買點數 (buy) | 啟動購買流程 |
| 贈送禮物 (gift) | 執行禮物贈送 |
| 查詢收到的禮物 (gift_received) | 查詢自己收到的禮物統計 |
| 群發通知 (announce) | 發送群發通知 |

### 預設指令

系統安裝後會自動建立以下預設指令：

| 指令名稱 | 行為類型 | 使用者輸入 |
|----------|----------|-----------|
| bind | 綁定帳號 | `!bind` |
| points | 查詢點數 | `!points` |
| buy | 購買點數 | `!buy 100` |
| gift | 贈送禮物 | `!gift @人 玫瑰 3` |
| mygifts | 查詢收到的禮物 | `!mygifts` |
| announce | 群發通知 | `!announce @組 訊息` |

### 如何自訂指令名稱

**情境：** 想讓用戶輸入 `!購買` 也能購買點數。

1. 點擊「新增」。
2. 指令名稱填入：`購買`
3. 行為類型選擇：購買點數 (buy)
4. 儲存。

此後，`!buy 100` 和 `!購買 100` 都可以觸發購買功能。

### 如何停用指令

將指令的「啟用」欄位取消勾選即可。停用後使用者輸入該指令不會有任何反應。

### 注意事項

- 指令名稱**不可重複**。
- 同一行為類型可以設定**多個**指令名稱（別名功能）。
- 修改後會**立即生效**，不需重啟 Bot。
