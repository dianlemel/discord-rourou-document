# 17. 群發通知

擁有特定身分組的使用者可以向指定身分組的所有成員發送私訊通知。

### 使用方式

```
!announce @身分組 通知內容
```

**範例：**

```
!announce @VIP 今晚 8 點有特別活動，請準時參加！
```

### 說明

- 機器人會逐一私訊該身分組的所有成員（不包含機器人帳號）。
- 發送完成後，您會收到一則結果回報，顯示成功與失敗的數量。

### 注意事項

- 只有被授權的身分組成員才能使用此功能（需在 Odoo 後台設定允許的身分組 ID）。
- 如果目標成員關閉了私訊接收，該成員將無法收到通知，但不影響其他成員。
- 成員數量較多時，發送可能需要一些時間，請耐心等待。
- 請避免頻繁使用此功能，以免造成成員困擾。
