# 10. 禮物庫存管理

管理每位使用者擁有的禮物庫存，管理員可直接從後台新增、編輯或刪除庫存記錄。

### 進入方式

**路徑：** Discord > 點數 > 禮物庫存

### 列表欄位

| 欄位 | 說明 |
|------|------|
| **擁有者** | 擁有此禮物的聯絡人 |
| **禮物** | 禮物項目 |
| **來源** | `自有` 或 `收到`（見下方說明） |
| **數量** | 目前庫存數量 |

### 來源說明

| 來源 | 說明 | 來源途徑 | 可否再贈送 |
|------|------|----------|-----------|
| **自有** | 自己購買或抽獎取得的禮物 | 購買禮物、抽獎中獎 | ✅ 可以 |
| **收到** | 別人贈送的禮物 | 被其他使用者贈送 | ❌ 不可以 |

同一使用者的同一禮物，自有和收到會分開記錄為**兩筆不同的庫存**。

### 直接編輯

列表視圖支援**行內編輯**（editable="bottom"），管理員可以直接在列表中：

- **新增記錄**：直接在列表底部輸入擁有者、禮物、來源和數量
- **修改數量**：點擊數量欄位直接修改
- **刪除記錄**：選取記錄後刪除

### 篩選與分組

**快速篩選：**
- 有庫存（預設啟用，僅顯示數量 > 0 的記錄）
- 自有（僅顯示自有來源）
- 收到（僅顯示收到來源）

**分組檢視：**
- 依擁有者分組
- 依禮物分組
- 依來源分組

### 庫存運作方式

- **自有庫存**：使用者透過「購買禮物」或「抽獎」取得的禮物會存入自有庫存，可以之後贈送給其他人。
- **收到庫存**：使用者被其他人贈送的禮物會存入收到庫存，**不可再轉送**。
- 管理員可以在後台**手動調整**庫存數量，用於：
  - 活動獎勵手動發放禮物
  - 客訴處理補發禮物
  - 修正異常資料
- 庫存數量**不能為負數**。

### 注意事項

- 此頁面的庫存即為禮物面板「庫存查詢」按鈕的資料來源。
- 可透過聯絡人頁面的「禮物庫存」智能按鈕快速查看特定用戶的庫存。
