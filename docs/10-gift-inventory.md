# 10. 禮物庫存管理

管理每位使用者擁有的禮物庫存，管理員可直接從後台新增、編輯或刪除庫存記錄。

### 進入方式

**路徑：** Discord > 點數 > 禮物庫存

### 列表欄位

| 欄位 | 說明 |
|------|------|
| **擁有者** | 擁有此禮物的聯絡人 |
| **禮物** | 禮物項目 |
| **數量** | 目前庫存數量 |

### 直接編輯

列表視圖支援**行內編輯**（editable="bottom"），管理員可以直接在列表中：

- **新增記錄**：直接在列表底部輸入擁有者、禮物和數量
- **修改數量**：點擊數量欄位直接修改
- **刪除記錄**：選取記錄後刪除

### 篩選與分組

**快速篩選：**
- 有庫存（預設啟用，僅顯示數量 > 0 的記錄）

**分組檢視：**
- 依擁有者分組
- 依禮物分組

### 庫存運作方式

- 當使用者透過 `!gift` 指令贈送禮物時，**接收者的庫存會自動增加**。
- 管理員可以在後台**手動調整**庫存數量，用於：
  - 活動獎勵手動發放禮物
  - 客訴處理補發禮物
  - 修正異常資料
- 同一使用者的同一禮物只會有**一筆庫存記錄**（系統有唯一性約束）。
- 庫存數量**不能為負數**。

### 注意事項

- 此頁面的庫存即為 `!mygifts` 指令查詢的資料來源。
- 可透過聯絡人頁面的「禮物庫存」智能按鈕快速查看特定用戶的庫存。
