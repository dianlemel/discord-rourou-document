# 23. 工單付款管理（後台）

管理工單付款的相關設定與付款記錄。

---

## 23.1 工單付款設定

### 進入方式

**路徑：** 設定 > 一般設定 > 往下捲動至「Discord」區塊 > 工單付款

### 設定欄位

| 欄位 | 說明 | 預設值 |
|------|------|--------|
| **付款指令允許身分組 ID** | 允許使用 `!pay` 指令的 Discord Role ID，多個以半形逗號分隔 | （空，未設定時無人可使用） |
| **付款成功通知身分組 ID** | 付款成功後在工單頻道 @ 通知的 Discord Role ID，多個以半形逗號分隔 | （空） |
| **銀行名稱** | 銀行匯款頁面顯示的銀行名稱 | （空） |
| **銀行帳號** | 銀行匯款頁面顯示的帳號 | （空） |
| **戶名** | 銀行匯款頁面顯示的戶名 | （空） |

### 欄位說明

**付款指令允許身分組 ID：** 控制誰可以在工單頻道中使用 `!pay` 指令建立付款單。只有擁有這些身分組的成員才能使用此指令。

**付款成功通知身分組 ID：** 當客戶完成付款時，系統會在工單頻道 @ 這些身分組，讓相關人員即時收到通知。

**銀行資訊：** 客戶選擇銀行匯款時，頁面上會顯示這些資訊。如果不填寫，銀行匯款頁面會顯示「-」。

---

## 23.2 工單付款管理

### 進入方式

**路徑：** Discord > 工單 > 工單付款

### 列表欄位

| 欄位 | 說明 |
|------|------|
| **付款單編號** | 系統自動產生（格式：TP + 時間戳） |
| **工單** | 關聯的工單 |
| **客戶** | 工單的客戶 |
| **金額** | 付款金額 |
| **狀態** | 待付款 / 已付款 / 付款失敗 / 已取消 |
| **付款方式** | 綠界 / 歐富寶 / 銀行匯款 |
| **建立時間** | 付款單建立的時間 |
| **付款時間** | 實際完成付款的時間 |

### 付款狀態說明

| 狀態 | 標示顏色 | 說明 |
|------|----------|------|
| **待付款** | 黃色 | 已建立，等待客戶付款 |
| **已付款** | 綠色 | 付款已完成 |
| **付款失敗** | 紅色 | 付款過程中發生錯誤 |
| **已取消** | 灰色 | 付款單已取消（管理員重新 `!pay` 時舊單自動取消） |

### 確認付款（銀行匯款）

銀行匯款有兩種確認方式：

**方式一：透過 Discord 確認（推薦）**

客戶在付款頁面點擊「我已完成匯款」後，系統會在工單頻道 @通知身分組，並附上「確認到帳」按鈕。擁有通知身分組的成員確認後點擊按鈕即可完成確認。

**方式二：透過 Odoo 後台確認**

1. 進入 Discord > 工單 > 工單付款。
2. 找到對應的付款記錄（狀態為「待付款」，付款方式為「銀行匯款」）。
3. 點擊進入表單。
4. 點擊上方的「**確認付款**」按鈕。
5. 系統會自動記錄付款時間，並在 Discord 工單頻道發送付款成功通知。

如需取消付款單，點擊「**取消**」按鈕（會有確認提示）。

> 綠界和歐富寶的付款由金流平台自動回調處理，不需要手動確認。

### 從工單查看付款記錄

除了從「工單付款」選單查看外，也可以從工單表單中直接查看：

1. 進入 Discord > 工單 > 工單管理。
2. 點擊任一工單進入表單。
3. 表單上方有「**付款**」統計按鈕，點擊可跳轉至該工單的付款記錄。
4. 表單下方「**付款記錄**」頁籤也會列出所有付款明細。

### 篩選與分組

**快速篩選：**
- 待付款（預設）/ 已付款 / 付款失敗 / 已取消

**分組檢視：**
- 依狀態分組
- 依工單分組
- 依客戶分組

## 23.3 訊息模板

工單付款使用兩個模板類型，可在「訊息模板」中自訂：

| 模板類型 | 觸發時機 | 可用變數 |
|----------|----------|----------|
| **工單付款通知** | 管理員執行 `!pay` 時 @客戶的訊息 | `{{ customer }}`（@ mention）、`{{ amount }}`（金額）、`{{ payment_url }}`（付款連結）、`{{ ticket_name }}`（工單編號）、`{{ payment_no }}`（付款單編號） |
| **工單付款成功通知** | 付款成功時在工單頻道的通知 | `{{ customer }}`（@ mention）、`{{ payment_no }}`（付款單編號）、`{{ amount }}`（金額）、`{{ ticket_name }}`（工單編號）、`{{ payment_method }}`（付款方式） |

> 模板編輯路徑：Discord > 設定 > 訊息模板

---

## 23.4 注意事項

- 付款記錄無法在後台手動新增或刪除，只能透過 Discord `!pay` 指令建立。
- 付款記錄有 Chatter 功能，狀態變更會自動記錄。
- 工單列表中的「已付款金額」欄位只計算已付款狀態的金額合計。
- 同一工單重複執行 `!pay` 時，上一筆待付款的付款單會自動取消，原付款連結訊息會被刪除。
- 付款成功後，系統會在工單頻道 @客戶和通知身分組，並刪除原付款連結訊息。
