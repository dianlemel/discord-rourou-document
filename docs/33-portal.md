# 26. 會員中心

「會員中心」是一個獨立的網頁，您透過 Discord 帳號授權登入後，可以查看自己的個人資料：

- 🎁 **禮物收藏圖鑑** — 已收集 / 未獲得的禮物
- 📦 **購買紀錄** — 點數購買訂單與付款狀態
- 💝 **贈送紀錄** — 送出與收到的禮物
- 🎰 **抽獎紀錄** — 抽獎結果與中獎獎品

---

## 進入方式

### 方式一：點擊面板按鈕（推薦）

管理員會在頻道中設置一個會員中心面板，上面有一個「**🌐 進入會員中心**」按鈕。

1. 找到會員中心面板，點擊「**進入會員中心**」按鈕。
2. 瀏覽器會在新分頁開啟會員中心網頁。
3. 首次使用需透過 Discord 帳號授權登入（詳見下方流程）。

### 方式二：直接開網址

也可以直接在瀏覽器輸入會員中心網址：

```
https://你的網域/discord/portal
```

---

## 首次登入流程

第一次進入會員中心時，需透過 Discord 帳號授權：

1. 進入會員中心首頁，看到「**使用 Discord 登入**」按鈕，點擊它。
2. 瀏覽器跳轉至 Discord 官方授權頁，會詢問是否允許讀取您的基本資料：
   - 您的 Discord 帳號 ID
   - 使用者名稱
   - 頭像
3. 點選「**授權**」（Authorize）按鈕。
4. 系統自動跳回會員中心首頁，您會看到右上角顯示您的頭像和名稱。

> 系統**只取得最基本的個人資料**，不會讀取您的伺服器列表、私訊內容或 email。
> 授權成功後，**7 天內**不需要重新授權；超過 7 天或主動登出後，需要重新授權。

### 關於自動建立帳號

如果您**從未綁定過**（沒用過 `!bind`），會員中心登入後會**自動為您建立帳號**，並嘗試下載您的 Discord 頭像作為個人圖像，您不需要再執行 `!bind`。

## 首頁

登入成功後，會看到首頁的功能卡片：

| 卡片 | 用途 |
|------|------|
| 🎁 禮物收藏 | 進入禮物收藏圖鑑 |
| 📦 購買紀錄 | 查看點數購買訂單 |
| 💝 贈送紀錄 | 查看贈送與收到的禮物 |
| 🎰 抽獎紀錄 | 查看抽獎結果 |

點選任一張卡片即可進入對應頁面。

頁面右上角顯示：
- 您的 Discord 頭像
- 您的使用者名稱
- 「**登出**」按鈕

---

## 🎁 禮物收藏圖鑑

展示所有禮物的收藏進度，類似遊戲圖鑑：

### 顯示規則

| 狀態 | 視覺呈現 |
|------|---------|
| **已獲得** | 彩色圖片 + 右上角藍色徽章顯示總擁有數量「×N」+ 卡片下方顯示首次獲得日期（📅 YYYY/MM/DD） |
| **未獲得** | 灰階圖片 + 名稱仍顯示 + 鎖定圖示（🔒） |

### 數量說明

「總擁有數量」= 您**自己購買** + **別人贈送**給您的數量加總。

**滑鼠停留**（hover）在已獲得的禮物上，會顯示細節：

```
自己買的 3 個
收到的 2 個
首次獲得 2025/01/15
```

> 「首次獲得日期」記錄您**第一次取得該禮物**的日期（不論是購買、收到還是抽獎）。即使後來把禮物送光，首次獲得日期不變。

### 進度條

頁面上方會顯示整體收集進度，例如「收集進度：12 / 30」與百分比。

## 📦 購買紀錄

列出您所有的點數購買訂單。

### 統計資訊（頁面上方）

- **總訂單數** — 包含所有狀態
- **已付款** — 已成功付款的訂單數
- **累計點數** — 您透過購買累計獲得的點數
- **累計金額** — 您透過購買支付的總金額

### 篩選

頁面上方有狀態篩選按鈕：

- **全部**
- **已付款**
- **待付款**
- **失敗**
- **已取消**

### 列表內容

每筆訂單顯示：

- 點數數量（💰 100 點）
- 狀態徽章（綠色＝已付款、黃色＝待付款、紅色＝失敗、灰色＝已取消）
- 付款方式（綠界 / 歐富寶 / PayPal）
- 訂單編號（PT 開頭）
- 付款失敗時的失敗原因
- 金額（NT$）
- 訂單建立時間

---

## 💝 贈送紀錄

列出您的禮物贈送紀錄，分成兩個分頁。

### 分頁切換

- **📤 送出** — 您送給別人的禮物
- **📥 收到** — 別人送給您的禮物

每個分頁的標題會顯示對應的筆數，例如「📤 送出（5）」。

### 統計資訊

- **送出筆數** — 您送出禮物的總筆數
- **收到筆數** — 您收到禮物的總筆數
- **送出累計點數** — 您送出禮物時消耗的總點數

### 列表內容

每筆紀錄顯示：

- 禮物縮圖
- 禮物名稱與數量（例如「鑽石 ×3」）
- 對方的名稱（送出時顯示「給 OOO」、收到時顯示「來自 OOO」）
- 點數消耗（送出時顯示「−100 點」表示扣除）
- 紀錄時間

### 庫存贈送的特殊標示

如果是「**從庫存贈送**」（不扣點數，從自己的禮物庫存扣除），右側會顯示紫色「庫存」徽章，且點數欄位顯示為「庫存」而非數字。

---

## 🎰 抽獎紀錄

列出您所有抽獎的結果。

### 統計資訊

- **總抽獎次數** — 您累計抽獎的次數
- **不重複獎品** — 您抽到的不同獎品種類數
- **累計消耗點數** — 您抽獎累計消耗的點數

### 篩選

如果您參加過多個抽獎活動，頁面會列出所有您抽過的活動，可以點擊任一活動只看該活動的紀錄。

### 列表內容

每筆紀錄顯示：

- 抽到獎品的縮圖
- 獎品名稱
- 抽獎活動名稱（紫色標籤）
- 該獎品的點數價值（例如「獎品價值 200 點」）
- 抽獎消耗點數（−50 點）
- 抽獎時間

---

## 登出

點選右上角「**登出**」按鈕，系統會：

1. 撤銷您目前的會員中心 session
2. 清除瀏覽器中的 cookie
3. 跳回登入頁

下次再進入會員中心時，需要重新透過 Discord 授權登入。

---

## 注意事項

### 安全建議

- **不要在公用電腦保持登入** — 使用完請主動點選「登出」，避免他人查看您的個人資料。
- **session 有效期為 7 天**，超過會自動失效，需重新授權。

### 若無法登入

- 請確認您的 Discord 帳號**沒被伺服器封鎖**。
- 確認您**已加入該伺服器**（會員中心顯示的禮物與紀錄與伺服器綁定）。
- 如果遇到「無效的 OAuth2 redirect_uri」錯誤，請聯繫管理員處理。

### 資料同步

- 您在 Discord 中購買、贈送、抽獎的紀錄會**即時同步**到會員中心。
- 如果剛剛操作完看不到資料，請按 **F5** 重新整理頁面。

## 常見問題

### Q1：頁面顯示我有禮物，但 `!mygifts` 顯示我沒有？

**不太可能發生**。會員中心和 `!mygifts` 讀取同一個資料來源。如果真的不一致，請按 F5 重整或聯繫管理員。

### Q2：可以查看別人的禮物收藏嗎？

不行。會員中心**只能查看您自己**的個人資料，無法查看他人。

### Q3：登入後一直跳回登入頁？

可能原因：
- 您的瀏覽器禁用了 cookie，請確認瀏覽器設定允許接收 cookie。
- 您使用的是無痕模式且關閉了視窗（無痕模式 cookie 會被清除）。

### Q4：手機可以使用嗎？

可以。會員中心採用**響應式設計**，手機、平板、桌面瀏覽器都能正常顯示。

### Q5：可以同時在多個裝置登入嗎？

可以。每個裝置會有獨立的 session，互不影響。
