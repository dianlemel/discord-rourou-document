# 派工設定與管理（後台）

管理派工系統的相關設定與派工記錄。

---

## 派工設定

### 進入方式

**路徑：** 設定 > 一般設定 > 往下捲動至「Discord」區塊 > 派工設定

### 設定欄位

| 欄位 | 說明 | 預設值 |
|------|------|--------|
| **允許身分組 ID** | 允許使用 `!assign` 指令的 Discord Role ID，多個以半形逗號分隔 | （空，未設定時無人可使用） |
| **頻道類別 ID** | 派工頻道建立時所屬的 Discord 類別 ID | （空，必須設定） |
| **頻道額外身分組 ID** | 派工頻道額外加入的 Discord Role ID，多個以半形逗號分隔 | （空） |

**格式範例（身分組 ID / 類別 ID）：**
```
123456789012345678,987654321098765432
```

### 欄位說明

**允許身分組 ID：** 控制誰可以在 Discord 工單頻道中輸入 `!assign` 指令。只有擁有這些身分組的成員才能使用此指令。此身分組同時也用於控制派工頻道的「刪除頻道」按鈕權限。

**頻道類別 ID：** 派工頻道會建立在此類別下方。如未設定，`!assign` 指令會提示需先在後台設定。

**頻道額外身分組 ID：** 派工頻道建立時，除了工單客戶（老闆）和被指派的工人之外，這些身分組的成員也會自動獲得頻道的讀寫權限。通常設定為管理員或客服身分組。

**如何取得 Discord 類別 ID：**

1. 確認已開啟 Discord 開發者模式。
2. 對目標類別（Category）**按右鍵** > 選擇「複製頻道 ID」。
3. 將 ID 貼入此欄位。

## 派工管理

### 進入方式

**路徑：** Discord > 工單 > 派工管理

### 列表欄位

| 欄位 | 說明 |
|------|------|
| **工單** | 對應的工單記錄 |
| **頻道名稱** | 派工頻道的名稱 |
| **工人** | 被指派的 Odoo 聯絡人（需已綁定帳號） |
| **狀態** | 開啟 / 已關閉 |
| **建立時間** | 派工記錄建立的時間 |
| **關閉時間** | 派工頻道被關閉的時間 |

### 派工狀態說明

| 狀態 | 標示顏色 | 說明 |
|------|----------|------|
| **開啟** | 綠色 | 派工頻道仍存在 |
| **已關閉** | 灰色 | 派工頻道已被刪除 |

### 派工表單

表單顯示派工的詳細資訊，包括對應工單、頻道名稱、頻道 ID、工人、建立時間、關閉時間。

### 篩選與分組

**快速篩選：**
- 開啟中（預設）/ 已關閉

**分組檢視：**
- 依狀態分組
- 依工單分組

### 在工單表單中查看派工記錄

工單表單上方顯示「**派工**」統計按鈕，點擊可跳轉至該工單的所有派工記錄。表單下方也有「派工記錄」頁籤，可直接查看派工明細。

### 頻道刪除自動偵測

若派工頻道在 Discord 中被手動刪除（例如管理員直接刪除頻道），系統會**自動偵測**並將對應的派工狀態更新為「已關閉」，同時記錄關閉時間。工單頻道中的派工通知訊息也會一併刪除。

### 注意事項

- 派工記錄無法在後台手動新增或刪除。
- 點擊工單欄位可跳轉至對應的工單頁面。
- 點擊工人欄位可跳轉至對應的聯絡人頁面。
- 若工人尚未綁定帳號，工人欄位會顯示為空，但不影響 Discord 端的功能。
- 一張工單可以有多筆派工記錄（多個派工頻道）。

## 訊息模板

派工系統使用兩個模板類型，可在「訊息模板」中自訂：

| 模板類型 | 觸發時機 | 可用變數 |
|----------|----------|----------|
| **派工通知** | 執行 `!assign` 時在工單頻道發送的通知 | `{{ user }}`（工單客戶 @ mention）、`{{ channel_mention }}`（新建頻道 # mention）、`{{ worker }}`（工人 @ mention） |
| **派工歡迎訊息** | 派工頻道建立後的歡迎訊息 | `{{ boss }}`（工單客戶 @ mention）、`{{ worker }}`（工人 @ mention）、`{{ channel_name }}`（頻道名稱） |

> 模板編輯路徑：Discord > 設定 > 訊息模板
