# 22. 工單系統（Discord 操作）

使用者可透過工單面板建立專屬的客服頻道，與支援人員一對一溝通。

---

### 建立工單

1. 管理員在頻道中執行 `!ticket_setup`，頻道內會出現一則面板訊息和「建立工單」按鈕。
2. 使用者點擊按鈕後，系統會在**同一類別**下自動建立一個新的文字頻道（例如 `ticket-0001`）。
3. 使用者會收到一則 ephemeral 訊息（僅自己可見），提示工單頻道已建立。
4. 在新頻道中，系統會發送歡迎訊息並 @ 提及使用者。

### 工單頻道權限

建立的工單頻道有以下權限設定：

| 對象 | 權限 |
|------|------|
| **@everyone** | 無法查看 |
| **建立者** | 可讀取、發送訊息、查看歷史訊息 |
| **支援身分組** | 可讀取、發送訊息、查看歷史訊息 |
| **機器人** | 可讀取、發送訊息、管理頻道 |

> 只有工單建立者和支援人員能看到工單頻道，其他成員無法查看。

### 關閉工單

1. 在工單頻道中，點擊歡迎訊息下方的「**關閉工單**」按鈕。
2. 系統會發送一則 ephemeral 確認訊息，提供「**確認關閉**」和「**取消**」兩個按鈕。
3. 點擊「確認關閉」後，頻道會被**刪除**，Odoo 中的工單記錄會自動更新為「已關閉」。
4. 點擊「取消」則不做任何操作。

### 自動綁定

如果使用者在點擊「建立工單」按鈕時尚未綁定帳號，系統會**自動建立聯絡人**（同 `!bind` 的效果），無需額外操作。

### 注意事項

- `!ticket_setup` 指令僅限被授權的身分組成員使用（需在 Odoo 後台設定）。
- 指令訊息會在面板發送後**自動刪除**，頻道中只會留下面板訊息。
- 面板上的按鈕在**機器人重啟後仍然有效**，不需要重新設定。
- 工單頻道關閉後無法恢復，請確保問題已解決再關閉。
- 支援身分組的設定請參考 [21. 工單設定](21-ticket-setup.md)。
