# 8. 購買訂單管理

查看和追蹤所有用戶的點數購買訂單。

### 進入方式

**路徑：** Discord > 點數 > 購買訂單

### 列表欄位

| 欄位 | 說明 |
|------|------|
| **訂單編號** | 系統自動產生（格式：PT + 時間戳記） |
| **客戶** | 綁定的 Odoo 聯絡人 |
| **Discord ID** | 用戶的 Discord ID |
| **點數** | 購買的點數數量 |
| **金額** | 付款金額（NT$） |
| **付款方式** | 綠界 / 歐富寶 / PayPal |
| **狀態** | 待付款 / 已付款 / 付款失敗 / 已取消 |
| **建立時間** | 訂單建立的時間 |

### 訂單狀態說明

| 狀態 | 標示顏色 | 說明 |
|------|----------|------|
| **待付款** | 黃色 | 訂單已建立，用戶尚未完成付款 |
| **已付款** | 綠色 | 付款成功，點數已加入帳戶 |
| **付款失敗** | 紅色 | 付款過程中發生錯誤，可在訂單詳情中查看失敗原因 |
| **已取消** | — | 訂單已取消 |

### 篩選與分組

**快速篩選：**
- 已付款 / 待付款 / 付款失敗
- 綠界 / 歐富寶 / PayPal

**分組檢視：**
- 依狀態分組
- 依付款方式分組
- 依客戶分組

### 注意事項

- 訂單為**唯讀**，無法在後台手動新增或刪除。
- 所有欄位皆為唯讀，訂單狀態由系統自動更新。
- 點擊訂單可查看詳細資訊，包含金流交易編號、付款時間，以及付款失敗時的失敗原因。
- 付款失敗的訂單無法再使用，客戶需重新購買以產生新訂單。
