# 4. 頻道設定

控制各指令可以在哪些 Discord 頻道中使用。

### 進入方式

**路徑：** Discord > 設定 > 頻道設定

### 欄位說明

| 欄位 | 說明 | 必填 |
|------|------|------|
| **頻道類型** | 對應的指令行為 | 是 |
| **頻道 ID** | Discord 頻道的數字 ID | 是 |
| **備註** | 方便辨識用的說明文字 | 否 |

### 頻道類型

| 類型 | 說明 |
|------|------|
| 綁定 (bind) | 允許執行綁定指令的頻道 |
| 點數查詢 (points) | 允許查詢點數的頻道 |
| 購買點數 (buy) | 允許購買指令的頻道 |
| 贈送禮物 (gift) | 允許贈送禮物指令的頻道 |
| 查詢收到的禮物 (gift_received) | 允許查詢收到禮物的頻道 |
| 群發通知 (announce) | 允許群發通知的頻道 |

### 運作邏輯

- 如果某行為**沒有設定任何頻道**，則該指令在**所有頻道**都可以使用。
- 如果某行為**設定了一個或多個頻道**，則該指令**只能在這些頻道**中使用，在其他頻道輸入會被靜默忽略。

### 設定範例

| 頻道類型 | 頻道 ID | 備註 |
|----------|---------|------|
| 綁定 | 1234567890 | #新手綁定 |
| 購買點數 | 9876543210 | #購買專區 |
| 購買點數 | 1111111111 | #VIP 購買 |

以上設定代表：
- `!bind` 只能在 #新手綁定 頻道使用。
- `!buy` 可以在 #購買專區 和 #VIP 購買 兩個頻道使用。
- `!points`、`!gift`、`!mygifts`、`!announce` 未設定頻道，因此在任何頻道都可使用。

### 注意事項

- 同一頻道不能對同一行為類型設定兩次。
- 修改後**立即生效**。
