# 14. 購買點數

透過線上付款購買點數，支援綠界科技（ECPay）、歐富寶（OPay）及 PayPal 三種付款方式。

---

### 方式一：點擊點數面板按鈕（推薦）

管理員會在頻道中設置一個點數面板，上面有「**購買點數**」按鈕。

1. 點擊「**購買點數**」按鈕。
2. 彈出一個輸入框，輸入要購買的**點數數量**。
3. 提交後，機器人會透過**私訊**發送付款連結。
4. 如果輸入格式錯誤（非正整數），會收到一則**僅您可見**的錯誤提示，**10 秒後自動消失**。

---

### 方式二：輸入指令

```
!buy <點數數量>
```

**範例：**

```
!buy 100
!buy 500
```

---

### 完整購買流程

1. **發送指令或點擊面板按鈕** — 指定購買的點數數量。
2. **收到付款連結** — 機器人會透過**私訊**發送一個包含「點擊付款」按鈕的訊息。
3. **點擊付款按鈕** — 點擊後將開啟付款頁面。
4. **選擇付款方式** — 頁面上可選擇「綠界科技」、「歐富寶」或「PayPal」。
5. **完成付款** — 依照金流商的指引完成付款程序。
6. **自動到帳** — 付款成功後，點數會**立即自動加入**您的帳戶，同時您會收到一則付款成功的私訊通知。

### 注意事項

- 點數數量必須為**正整數**（如 1、50、100），不接受小數或負數。
- 付款連結為**一次性使用**，付款完成或過期後將自動失效。
- 付款完成後，原本的付款連結訊息會自動刪除。
- 如果付款失敗，付款結果頁面會顯示「付款失敗」，該訂單將無法再使用，需重新購買產生新訂單。
- 如果付款過程中遇到其他問題，請勿重複購買，先聯繫管理員確認訂單狀態。
- 實際付款金額 = 點數 × 點數單價（實際單價請以付款頁面顯示為準）。
