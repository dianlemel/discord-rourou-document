# 12. 帳號綁定

在使用任何功能之前，您必須先將 Discord 帳號與系統進行綁定。

---

### 方式一：點擊綁定面板按鈕（推薦）

管理員會在頻道中設置一個綁定面板，上面有一個「**綁定**」按鈕。

1. 找到綁定面板，點擊「**綁定**」按鈕。
2. 系統會顯示一則**僅您可見**的訊息，告知綁定結果。
3. 該訊息會在 **10 秒後自動消失**。

---

### 方式二：輸入指令

在允許的頻道中輸入：

```
!bind
```

機器人會透過**私訊**通知您綁定結果。

---

### 說明

- 機器人會自動讀取您的 Discord 名稱與頭像，並在系統中建立您的帳號。
- 每個 Discord 帳號只能綁定一次，重複綁定會提示「已經綁定」並顯示您目前的點數。

### 管理員：設置綁定面板

在任意頻道中輸入以下指令，即可發送綁定面板：

```
!bind_setup
```

- 此指令**不限頻道**，但需要擁有被授權的身分組才能使用（需在 Odoo 後台設定）。
- 指令訊息會在面板發送後**自動刪除**，頻道中只會留下面板訊息。
- 面板上的按鈕在**機器人重啟後仍然有效**，不需要重新設定。

### 注意事項

- 請確保您的 Discord **隱私設定**允許接收來自伺服器成員的私訊，否則使用 `!bind` 指令時機器人無法傳送通知給您（使用面板按鈕則不受此限制）。
- 綁定後無法自行解除，如需更改請聯繫管理員。
