# 21. 工單設定（後台）

管理工單系統的相關設定與工單記錄。

---

## 21.1 工單設定

### 進入方式

**路徑：** 設定 > 一般設定 > 往下捲動至「Discord」區塊 > 工單設定

### 設定欄位

| 欄位 | 說明 | 預設值 |
|------|------|--------|
| **允許身分組 ID** | 允許使用 `!ticket_setup` 指令的 Discord Role ID，多個以半形逗號分隔 | （空，未設定時無人可使用） |
| **支援身分組 ID** | 建立工單時自動加入頻道權限的 Discord Role ID，多個以半形逗號分隔 | （空） |
| **頻道前綴** | 工單頻道的名稱前綴 | `ticket` |
| **建立按鈕文字** | 面板上建立按鈕的顯示文字 | `建立工單` |

**格式範例（身分組 ID）：**
```
123456789012345678,987654321098765432
```

### 欄位說明

**允許身分組 ID：** 控制誰可以在 Discord 中輸入 `!ticket_setup` 指令來發送工單面板。只有擁有這些身分組的成員才能使用此指令。

**支援身分組 ID：** 當使用者建立工單時，系統會自動讓這些身分組的成員也能看到並回覆該工單頻道。通常設定為客服或管理員身分組。

**頻道前綴：** 工單頻道的命名格式為 `{前綴}-{流水號}`，例如 `ticket-0001`、`ticket-0002`。

## 21.2 工單管理

### 進入方式

**路徑：** Discord > 工單 > 工單管理

### 列表欄位

| 欄位 | 說明 |
|------|------|
| **工單編號** | 系統自動產生的流水號（格式：0001、0002...） |
| **客戶** | 建立工單的 Odoo 聯絡人（透過 Discord 帳號綁定） |
| **已付款金額** | 該工單所有已付款的付款單金額合計 |
| **狀態** | 開啟 / 已關閉 |
| **建立時間** | 工單建立的時間 |
| **關閉時間** | 工單關閉的時間 |

### 工單狀態說明

| 狀態 | 標示顏色 | 說明 |
|------|----------|------|
| **開啟** | 綠色 | 工單進行中，頻道仍存在 |
| **已關閉** | 灰色 | 工單已關閉，頻道已刪除 |

### 工單表單

工單表單上方顯示「**付款**」統計按鈕，點擊可跳轉至該工單的所有付款記錄。表單下方有「付款記錄」頁籤，可直接查看付款明細。

### 後台修改狀態

後台人員可以直接在工單表單中點擊上方的「**關閉工單**」按鈕來關閉工單：

- 關閉時，系統會自動記錄關閉時間，並**嘗試刪除對應的 Discord 頻道**（若頻道已不存在則忽略）。

### 批次關閉

在列表視圖中，可以**勾選多筆工單**，然後從上方的「動作」下拉選單選擇「**關閉**」，即可批次關閉多筆工單。批次關閉時，對應的 Discord 頻道也會一併刪除。

### 篩選與分組

**快速篩選：**
- 開啟中（預設）/ 已關閉

**分組檢視：**
- 依狀態分組
- 依客戶分組

### 頻道刪除自動偵測

若工單頻道在 Discord 中被手動刪除（例如管理員直接刪除頻道），系統會**自動偵測**並將對應的工單狀態更新為「已關閉」，無需額外操作。

### 注意事項

- 工單無法在後台手動新增或刪除，但可以關閉。
- 點擊客戶欄位可跳轉至對應的聯絡人頁面。
- 工單有 Chatter 功能，狀態變更會自動記錄。
- 從後台關閉工單與從 Discord 關閉效果相同，都會刪除對應頻道。
- 若頻道在 Discord 端被手動刪除，系統會自動關閉對應工單，不會留下「開啟中但頻道已不存在」的孤立記錄。
- 工單付款的詳細說明請參考 [23. 工單付款管理](23-ticket-payment-setup.md)。

## 21.3 訊息模板

工單系統使用兩個模板類型，可在「訊息模板」中自訂：

| 模板類型 | 觸發時機 | 可用變數 |
|----------|----------|----------|
| **工單面板** | 執行 `!ticket_setup` 時發送到頻道 | （無） |
| **工單歡迎訊息** | 工單建立後發送到新頻道 | `{{ user }}`（@ mention）、`{{ username }}`（名稱）、`{{ ticket_name }}`（頻道名稱） |
| **工單付款通知** | 管理員執行 `!pay` 時 @客戶的訊息 | `{{ customer }}`（@ mention）、`{{ amount }}`（金額）、`{{ payment_url }}`（付款連結）、`{{ ticket_name }}`（工單編號）、`{{ payment_no }}`（付款單編號） |
| **工單付款成功通知** | 付款成功時在工單頻道的通知 | `{{ customer }}`（@ mention）、`{{ payment_no }}`（付款單編號）、`{{ amount }}`（金額）、`{{ ticket_name }}`（工單編號）、`{{ payment_method }}`（付款方式） |

> 模板編輯路徑：Discord > 設定 > 訊息模板
