# 9. 贈送紀錄管理

查看所有用戶之間的禮物贈送紀錄。

### 進入方式

**路徑：** Discord > 點數 > 贈送紀錄

### 列表欄位

| 欄位 | 說明 |
|------|------|
| **贈送時間** | 贈送發生的時間 |
| **贈送者** | 贈送方的聯絡人 |
| **接收者** | 接收方的聯絡人 |
| **禮物** | 贈送的禮物項目 |
| **數量** | 贈送的禮物數量 |
| **消耗點數** | 此次贈送消耗的總點數（禮物單價 × 數量） |

### 篩選與分組

**快速篩選：**
- 今日 / 近 7 天 / 近 30 天

**分組檢視：**
- 依禮物分組
- 依贈送者分組
- 依接收者分組
- 依日期分組

### 注意事項

- 贈送紀錄為**唯讀**，無法在後台手動新增或刪除。
- 可透過聯絡人頁面的「贈送紀錄」或「接收紀錄」智能按鈕快速查看特定用戶的紀錄。
