# 16. 查詢收到的禮物

查看您目前擁有的所有禮物及數量。

### 使用方式

```
!mygifts
```

### 說明

- 機器人會透過**私訊**回覆您目前的禮物庫存清單和數量。
- 結果會依禮物類型和來源列出，例如：
  ```
  🎒 自有禮物（可贈送）
  🎁 玫瑰花 x5
  🎁 巧克力 x2

  🎀 收到的禮物
  🎁 鑽石戒指 x1
  ```
- 如果目前沒有任何禮物庫存，會顯示「目前沒有任何禮物」。

### 禮物來源說明

| 來源 | 說明 |
|------|------|
| **自有** | 您透過購買或抽獎獲得的禮物，可以贈送給其他人 |
| **收到** | 別人贈送給您的禮物，不可再轉送 |

### 注意事項

- 必須先完成帳號綁定才能使用。
- 顯示的是您目前的**禮物庫存數量**，管理員可從後台調整庫存。
- 也可以透過禮物面板的「**庫存查詢**」按鈕查看相同資訊。
