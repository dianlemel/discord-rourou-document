# 13. 查詢點數

隨時查看您目前的點數餘額。

---

### 方式一：點擊點數面板按鈕（推薦）

管理員會在頻道中設置一個點數面板，上面有「**點數查詢**」和「**購買點數**」兩個按鈕。

1. 找到點數面板，點擊「**點數查詢**」按鈕。
2. 系統會顯示一則**僅您可見**的訊息，告知您目前的點數餘額。
3. 該訊息會在 **10 秒後自動消失**。

---

### 方式二：輸入指令

```
!points
```

機器人會透過**私訊**回覆您目前的點數餘額。

---

### 說明

- 使用面板按鈕查詢時，結果僅自己可見，不會打擾其他人。
- 使用指令查詢時，機器人透過私訊回覆，不會在頻道中公開顯示。

### 注意事項

- 必須先完成帳號綁定才能使用。
- 如果使用指令方式未收到私訊，請檢查您的 Discord 隱私設定（使用面板按鈕則不受此限制）。
