# 25. 禮物面板

管理員可透過指令在頻道中發送一個禮物面板，讓使用者透過按鈕操作禮物相關功能，不需要記憶指令。

---

### 管理員：設置禮物面板

在任意頻道中輸入以下指令：

```
!gift_setup
```

也可以自訂四個按鈕的文字：

```
!gift_setup 庫存查詢 贈送禮物 購買禮物 禮物列表
```

- 第一個參數為**庫存查詢按鈕**的文字（預設「庫存查詢」）。
- 第二個參數為**贈送禮物按鈕**的文字（預設「贈送禮物」）。
- 第三個參數為**購買禮物按鈕**的文字（預設「購買禮物」）。
- 第四個參數為**禮物列表按鈕**的文字（預設「禮物列表」）。
- 不帶參數則使用預設值。

---

### 面板功能

面板包含四個按鈕：

| 按鈕 | 功能 | 說明 |
|------|------|------|
| **庫存查詢** | 查詢禮物庫存 | 顯示自有和收到的禮物庫存，10 秒後自動消失 |
| **贈送禮物** | 從庫存贈送禮物 | 從自有庫存中選擇禮物贈送給其他人（不扣點） |
| **購買禮物** | 購買禮物 | 花點數購買禮物，可選擇立即贈送或放入庫存 |
| **禮物列表** | 查看所有禮物 | 列出所有可用禮物及點數消耗，10 秒後自動消失 |

---

### 使用者操作

#### 庫存查詢

1. 點擊「**庫存查詢**」按鈕。
2. 系統顯示一則**僅您可見**的訊息，列出您的禮物庫存，分為兩類：
   - 🎒 **自有禮物**（可贈送）：您購買或抽獎獲得的禮物
   - 🎀 **收到的禮物**：別人贈送給您的禮物（不可再轉送）
3. 該訊息會在 **10 秒後自動消失**。

#### 贈送禮物（從庫存）

1. 點擊「**贈送禮物**」按鈕。
2. 系統顯示**僅您可見**的介面，列出您的自有庫存中的禮物。
3. 操作步驟：
   - **選擇禮物**：從下拉選單中選擇要贈送的禮物（顯示名稱與庫存數量）。
   - **點擊「確認」**：彈出輸入框，輸入贈送數量。
   - **選擇對象**：選擇贈送對象。
   - **點擊「確認贈送」**：系統從您的庫存扣除，送達對方。
4. **不扣點數**，僅從您的自有庫存中扣除。
5. 對方收到的禮物為「收到」來源，不可再轉送。

#### 購買禮物

1. 點擊「**購買禮物**」按鈕。
2. 系統顯示**僅您可見**的購買介面，包含您目前的點數餘額。
3. 操作步驟：
   - **選擇禮物**：從下拉選單中選擇要購買的禮物（顯示名稱與點數消耗）。
   - **點擊「確認購買」**：彈出輸入框，輸入購買數量。
   - **提交數量**：系統扣除點數，禮物存入您的自有庫存。
4. 購買成功後可以選擇：
   - **立即贈送**：選擇贈送對象，直接送出。
   - **放入庫存**：保留在自有庫存中，之後再決定。
5. 超時未選擇將自動放入庫存。

#### 禮物列表

1. 點擊「**禮物列表**」按鈕。
2. 系統顯示一則**僅您可見**的訊息，列出所有可用禮物的名稱與點數消耗。
3. 該訊息會在 **10 秒後自動消失**。

### 相關訊息模板

| 模板類型 | 用途 | 說明 |
|----------|------|------|
| **禮物面板** | 面板本身的 Embed 訊息 | 面板類型，只能有一筆啟用 |
| **禮物庫存查詢** | 庫存查詢結果 | 區分自有與收到的禮物 |
| **購買禮物提示** | 點擊「購買禮物」後的提示訊息 | 支援 `{{ points }}` 變數顯示剩餘點數 |
| **庫存贈送成功通知** | 從庫存贈送完成後的私訊 | 顯示禮物名稱、數量、接收者 |
| **贈送成功通知** | 購買+直接贈送完成後的私訊 | 顯示禮物名稱、數量、消耗點數等 |
| **贈送公告** | 公告頻道的通知 | 顯示贈送者、接收者、禮物資訊 |
| **禮物列表** | 禮物列表查詢結果 | 顯示所有可用禮物 |

---

### 注意事項

- `!gift_setup` 指令僅限被授權的身分組成員使用（需在 Odoo 後台「禮物面板」區塊設定）。
- 指令訊息會在面板發送後**自動刪除**，頻道中只會留下面板訊息。
- 面板上的按鈕在**機器人重啟後仍然有效**，不需要重新設定。
- 使用者必須先完成帳號綁定才能使用面板功能。
- **收到的禮物不可再轉送**，只有自有庫存的禮物可以贈送。
- 現有的 `!gift` 文字指令仍然可以使用（直接扣點贈送）。
