# 11. 聯絡人整合

Discord 模組會在 Odoo 聯絡人上新增額外欄位和功能。

### 進入方式

**路徑：** 聯絡人 > 點擊任一聯絡人

### 新增欄位

| 欄位 | 說明 | 可編輯 |
|------|------|--------|
| **Discord ID** | 綁定的 Discord 用戶 ID | 否（唯讀） |
| **點數** | 該用戶的點數餘額 | 是（可手動調整） |

### 智能按鈕

聯絡人表單上方會顯示四個智能按鈕：

| 按鈕 | 圖示 | 功能 |
|------|------|------|
| **購買訂單** | 購物車 | 點擊後顯示該聯絡人的所有購買訂單 |
| **贈送紀錄** | 禮物 | 點擊後顯示該聯絡人**送出**的贈送紀錄 |
| **接收紀錄** | 愛心 | 點擊後顯示該聯絡人**收到**的贈送紀錄 |
| **禮物庫存** | 檔案櫃 | 點擊後顯示該聯絡人目前**擁有的禮物庫存**（數量 > 0） |

### 手動調整點數

管理員可以直接在聯絡人表單中修改「點數」欄位，用於：

- 客訴處理時手動補點
- 活動獎勵手動發放
- 修正異常資料

> 點數欄位有變更追蹤功能，所有修改都會記錄在聯絡人的 Chatter（討論記錄）中。

### 注意事項

- 每個 Discord 帳號只能綁定**一個**聯絡人，系統有唯一性約束。
- 在聯絡人列表視圖中，也可以選擇顯示 Discord ID 和點數欄位。
