## 1. 帳號綁定

在使用任何功能之前，您必須先將 Discord 帳號與系統進行綁定。

### 使用方式

在允許的頻道中輸入：

```
!bind
```

### 說明

- 機器人會自動讀取您的 Discord 名稱與頭像，並在系統中建立您的帳號。
- 綁定成功後，機器人會透過**私訊**通知您。
- 每個 Discord 帳號只能綁定一次，重複綁定會提示「已經綁定」並顯示您目前的點數。

### 注意事項

- 請確保您的 Discord **隱私設定**允許接收來自伺服器成員的私訊，否則機器人無法傳送通知給您。
- 綁定後無法自行解除，如需更改請聯繫管理員。

## 2. 查詢點數

隨時查看您目前的點數餘額。

### 使用方式

```
!points
```

### 說明

- 機器人會透過**私訊**回覆您目前的點數餘額。
- 此指令不會在頻道中公開顯示您的點數。

### 注意事項

- 必須先完成帳號綁定才能使用。
- 如果未收到私訊，請檢查您的 Discord 隱私設定。

## 3. 購買點數

透過線上付款購買點數，支援綠界科技（ECPay）及歐富寶（OPay）兩種付款方式。

### 使用方式

```
!buy <點數數量>
```

**範例：**

```
!buy 100
!buy 500
```

### 完整購買流程

1. **發送指令** — 在允許的頻道輸入 `!buy 100`（以購買 100 點為例）。
2. **收到付款連結** — 機器人會透過**私訊**發送一個包含「點擊付款」按鈕的訊息。
3. **點擊付款按鈕** — 點擊後將開啟付款頁面。
4. **選擇付款方式** — 頁面上可選擇「綠界科技」或「歐富寶」。
5. **完成付款** — 依照金流商的指引完成付款程序。
6. **自動到帳** — 付款成功後，點數會**立即自動加入**您的帳戶，同時您會收到一則付款成功的私訊通知。

### 注意事項

- 點數數量必須為**正整數**（如 1、50、100），不接受小數或負數。
- 付款連結為**一次性使用**，付款完成或過期後將自動失效。
- 付款完成後，原本的付款連結訊息會自動刪除。
- 如果付款過程中遇到問題，請勿重複購買，先聯繫管理員確認訂單狀態。
- 實際付款金額 = 點數 × 點數單價（實際單價請以付款頁面顯示為準）。

## 4. 贈送點數

將您的點數贈送給其他已綁定的使用者。

### 使用方式

```
!gift @對方 <點數數量>
!gift @對方 <點數數量> <備註>
```

**範例：**

```
!gift @John 50
!gift @John 100 感謝你的幫助
```

### 說明

- 贈送後，您的點數會立即扣除，對方會立即收到點數。
- 贈送成功後，機器人會透過**私訊**通知您贈送結果及剩餘點數。
- 如果伺服器有設定贈送公告頻道，贈送紀錄會在該頻道公開顯示。

### 注意事項

- **雙方都必須已完成帳號綁定**，否則無法贈送。
- 您的點數餘額必須**大於或等於**贈送數量。
- **不能贈送給自己**。
- 點數數量必須為**正整數**。
- 贈送一旦完成即**無法撤回**，請確認對象和數量後再操作。
- 備註為選填，可用來記錄贈送原因。

## 5. 群發通知功能

擁有特定身分組的使用者可以向指定身分組的所有成員發送私訊通知。

### 使用方式

```
!announce @身分組 通知內容
```

**範例：**

```
!announce @VIP 今晚 8 點有特別活動，請準時參加！
```

### 說明

- 機器人會逐一私訊該身分組的所有成員（不包含機器人帳號）。
- 發送完成後，您會收到一則結果回報，顯示成功與失敗的數量。

### 注意事項

- 只有被授權的身分組成員才能使用此功能。
- 如果目標成員關閉了私訊接收，該成員將無法收到通知，但不影響其他成員。
- 成員數量較多時，發送可能需要一些時間，請耐心等待。
- 請避免頻繁使用此功能，以免造成成員困擾。

## 6. 常見問題 FAQ

### Q：我輸入指令後沒有任何反應？

**可能原因：**

- **尚未綁定帳號** — 請先使用 `!bind` 完成綁定。
- **在錯誤的頻道** — 部分指令可能限制只能在特定頻道使用，請確認您在正確的頻道。
- **指令已被停用** — 管理員可能暫時停用了該指令。
- **指令格式錯誤** — 請確認指令格式正確，例如 `!buy` 後面必須接數字。

### Q：我收不到機器人的私訊？

**解決方式：**

1. 開啟 Discord **使用者設定**。
2. 進入「隱私與安全」。
3. 開啟「允許來自伺服器成員的私人訊息」。

### Q：付款成功但點數沒有到帳？

- 通常點數會在付款完成後**立即到帳**。
- 如果超過數分鐘仍未收到，請聯繫管理員並提供您的 Discord 名稱和付款時間。

### Q：我可以將點數轉回現金嗎？

- 點數**無法**兌換為現金或退款，購買前請確認需求。

### Q：贈送錯對象了怎麼辦？

- 點數贈送一旦完成即**無法撤回**，請在贈送前仔細確認對象和數量。如有特殊情況請聯繫管理員協助處理。

### Q：我的指令名稱和上面寫的不一樣？

- 管理員可能自訂了指令名稱。請詢問伺服器管理員確認目前使用的指令名稱。

## 7. 注意事項

### 帳號安全

- 請勿將您的 Discord 帳號借給他人使用，您的帳號與點數直接綁定。
- 如果懷疑帳號被盜用，請立即修改 Discord 密碼並聯繫管理員。

### 付款安全

- 所有付款均透過**綠界科技**或**歐富寶**等第三方合規金流平台處理，您的付款資料不會經過 Discord 機器人。
- 請勿在 Discord 頻道中透露任何付款資訊（如信用卡號等）。

### 頻道訊息自動刪除

- 部分頻道可能設有**訊息自動刪除**功能，您發送的訊息可能在數秒後被自動清除。
- 這是正常現象，不影響指令的執行。機器人的回覆會透過私訊傳送給您。

### 使用規範

- 請勿在短時間內大量重複發送指令，以免觸發速率限制。
- 請遵守伺服器的使用規範，濫用機器人功能可能導致權限被限制。
