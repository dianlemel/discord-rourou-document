# 第一部分：Odoo 後台設定

> 此部分為管理員操作指南，說明如何在 Odoo 後台進行模組的各項設定。

---

## 1. 基本設定

### 進入方式

**路徑：** 設定 > 一般設定 > 往下捲動至「Discord」區塊

### 1.1 Bot Token

| 欄位 | 說明 |
|------|------|
| **Bot Token** | Discord 機器人的身份驗證令牌（密碼欄位，輸入後不會明文顯示） |

**如何取得 Bot Token：**

1. 前往 [Discord Developer Portal](https://discord.com/developers/applications)。
2. 點擊「New Application」建立應用程式。
3. 左側選單進入「Bot」頁面。
4. 點擊「Reset Token」取得 Token，並複製貼入此欄位。
5. 在「Bot」頁面下方，開啟以下 **Privileged Gateway Intents**：
   - `MESSAGE CONTENT INTENT`（讀取訊息內容）
   - `SERVER MEMBERS INTENT`（讀取成員列表，群發通知需要）

> **重要：** Token 僅會顯示一次，請妥善保存。如果遺失需重新產生。

### 1.2 重啟 Bot

設定頁面上有一個「**重啟 Bot**」按鈕，當修改了 Token 或需要手動重啟機器人時，點擊此按鈕即可。

> 一般情況下，修改設定後系統會自動同步，**不需要手動重啟**。

### 1.3 點數單價

| 欄位 | 說明 | 預設值 |
|------|------|--------|
| **點數單價** | 每點的售價（單位：元） | 10 |

此設定影響用戶購買點數時的付款金額計算：

```
付款金額 = 購買點數 × 點數單價
```

**範例：** 單價設為 10 元，用戶購買 100 點 → 付款金額為 NT$ 1,000。

### 1.4 贈送公告頻道

| 欄位 | 說明 |
|------|------|
| **公告頻道 ID** | 當用戶贈送點數時，系統會在此頻道發送公告訊息 |

**如何取得 Discord 頻道 ID：**

1. 在 Discord 中開啟「使用者設定 > 進階 > 開發者模式」。
2. 對目標頻道**按右鍵** > 選擇「複製頻道 ID」。
3. 將 ID 貼入此欄位。

> 如果不填寫，贈送時將不會發送公告。

### 1.5 群發通知 — 允許身分組 ID

| 欄位 | 說明 |
|------|------|
| **允許身分組 ID** | 允許使用 `!announce` 指令的 Discord 身分組 ID，多個以**半形逗號**分隔 |

**格式範例：**
```
123456789012345678,987654321098765432
```

**如何取得身分組 ID：**

1. 確認已開啟 Discord 開發者模式。
2. 進入「伺服器設定 > 身分組」。
3. 對目標身分組**按右鍵** > 選擇「複製身分組 ID」。

> 只有擁有這些身分組的成員才能使用群發通知指令。

## 2. 金流設定

系統支援兩種金流服務，可以同時啟用，也可以只啟用其中一種。

### 進入方式

**路徑：** 設定 > 一般設定 > 往下捲動至「Discord」區塊 > 綠界科技 / 歐富寶

### 2.1 綠界科技（ECPay）

| 欄位 | 說明 |
|------|------|
| **測試模式** | 勾選後使用綠界的**測試環境**（用於開發測試，不會真正扣款） |
| **商店代號** | 綠界分配的 MerchantID |
| **HashKey** | API 驗證密鑰（密碼欄位） |
| **HashIV** | API 驗證初始向量（密碼欄位） |

**申請方式：** 前往 [綠界科技官網](https://www.ecpay.com.tw/) 註冊商店帳號，取得以上資訊。

### 2.2 歐富寶（OPay）

| 欄位 | 說明 |
|------|------|
| **測試模式** | 勾選後使用歐富寶的**測試環境** |
| **商店代號** | 歐富寶分配的 MerchantID |
| **HashKey** | API 驗證密鑰（密碼欄位） |
| **HashIV** | API 驗證初始向量（密碼欄位） |

**申請方式：** 前往 [歐富寶官網](https://www.opay.tw/) 註冊商店帳號，取得以上資訊。

### 注意事項

- **測試模式** 僅供開發或測試時使用，正式上線前請務必**取消勾選**。
- HashKey 和 HashIV 為敏感資訊，系統以密碼形式儲存，輸入後不會明文顯示。
- 如果兩種金流都沒有設定，用戶在付款頁面將無法選擇任何付款方式。
- 至少需要完成**一種**金流的設定，購買功能才能正常運作。

## 3. 指令設定

管理 Discord 機器人可辨識的指令名稱，支援自訂指令名稱與別名。

### 進入方式

**路徑：** Discord > 設定 > 指令設定

### 欄位說明

| 欄位 | 說明 | 必填 |
|------|------|------|
| **指令名稱** | 使用者輸入的指令文字（不含 `!` 前綴） | 是 |
| **行為類型** | 此指令觸發的功能 | 是 |
| **說明** | 備註用途（不會顯示在 Discord 上） | 否 |
| **啟用** | 是否啟用此指令 | — |

### 行為類型

| 類型 | 說明 |
|------|------|
| 綁定帳號 (bind) | 執行帳號綁定 |
| 查詢點數 (points) | 查詢點數餘額 |
| 購買點數 (buy) | 啟動購買流程 |
| 贈送點數 (gift) | 執行點數贈送 |
| 群發通知 (announce) | 發送群發通知 |

### 預設指令

系統安裝後會自動建立以下預設指令：

| 指令名稱 | 行為類型 | 使用者輸入 |
|----------|----------|-----------|
| bind | 綁定帳號 | `!bind` |
| points | 查詢點數 | `!points` |
| buy | 購買點數 | `!buy 100` |
| gift | 贈送點數 | `!gift @人 50` |
| announce | 群發通知 | `!announce @組 訊息` |

### 如何自訂指令名稱

**情境：** 想讓用戶輸入 `!購買` 也能購買點數。

1. 點擊「新增」。
2. 指令名稱填入：`購買`
3. 行為類型選擇：購買點數 (buy)
4. 儲存。

此後，`!buy 100` 和 `!購買 100` 都可以觸發購買功能。

### 如何停用指令

將指令的「啟用」欄位取消勾選即可。停用後使用者輸入該指令不會有任何反應。

### 注意事項

- 指令名稱**不可重複**。
- 同一行為類型可以設定**多個**指令名稱（別名功能）。
- 修改後會**立即生效**，不需重啟 Bot。

## 4. 頻道設定

控制各指令可以在哪些 Discord 頻道中使用。

### 進入方式

**路徑：** Discord > 設定 > 頻道設定

### 欄位說明

| 欄位 | 說明 | 必填 |
|------|------|------|
| **頻道類型** | 對應的指令行為 | 是 |
| **頻道 ID** | Discord 頻道的數字 ID | 是 |
| **備註** | 方便辨識用的說明文字 | 否 |

### 頻道類型

| 類型 | 說明 |
|------|------|
| 綁定 (bind) | 允許執行綁定指令的頻道 |
| 點數查詢 (points) | 允許查詢點數的頻道 |
| 購買點數 (buy) | 允許購買指令的頻道 |
| 贈送點數 (gift) | 允許贈送指令的頻道 |
| 群發通知 (announce) | 允許群發通知的頻道 |

### 運作邏輯

- 如果某行為**沒有設定任何頻道**，則該指令在**所有頻道**都可以使用。
- 如果某行為**設定了一個或多個頻道**，則該指令**只能在這些頻道**中使用，在其他頻道輸入會被靜默忽略。

### 設定範例

| 頻道類型 | 頻道 ID | 備註 |
|----------|---------|------|
| 綁定 | 1234567890 | #新手綁定 |
| 購買點數 | 9876543210 | #購買專區 |
| 購買點數 | 1111111111 | #VIP 購買 |

以上設定代表：
- `!bind` 只能在 #新手綁定 頻道使用。
- `!buy` 可以在 #購買專區 和 #VIP 購買 兩個頻道使用。
- `!points`、`!gift`、`!announce` 未設定頻道，因此在任何頻道都可使用。

### 注意事項

- 同一頻道不能對同一行為類型設定兩次。
- 修改後**立即生效**。

## 5. 自動刪除頻道

設定指定頻道的訊息在發送後自動刪除，適合用於指令頻道，保持頻道整潔。

### 進入方式

**路徑：** Discord > 設定 > 自動刪除頻道

### 欄位說明

| 欄位 | 說明 | 預設值 |
|------|------|--------|
| **頻道 ID** | Discord 頻道的數字 ID | （必填） |
| **頻道名稱** | 方便辨識用的名稱 | （選填） |
| **刪除延遲（秒）** | 訊息發送後幾秒刪除 | 5 |
| **刪除管理員訊息** | 是否刪除具有管理員權限的成員的訊息 | 否 |
| **刪除機器人訊息** | 是否刪除機器人發送的訊息 | 否 |
| **刪除一般使用者訊息** | 是否刪除一般使用者的訊息 | 是 |
| **啟用** | 是否啟用此規則 | 是 |

### 設定範例

**場景一：指令頻道（只保留管理員和機器人的訊息）**

| 欄位 | 值 |
|------|-----|
| 頻道 ID | 1234567890 |
| 頻道名稱 | #指令區 |
| 刪除延遲 | 5 秒 |
| 刪除管理員訊息 | 否 |
| 刪除機器人訊息 | 否 |
| 刪除一般使用者訊息 | 是 |

**場景二：臨時訊息頻道（所有訊息都刪除）**

| 欄位 | 值 |
|------|-----|
| 頻道 ID | 9876543210 |
| 頻道名稱 | #臨時對話 |
| 刪除延遲 | 10 秒 |
| 刪除管理員訊息 | 是 |
| 刪除機器人訊息 | 是 |
| 刪除一般使用者訊息 | 是 |

### 注意事項

- 每個頻道只能設定**一筆**自動刪除規則。
- 自動刪除**不影響指令的執行**，機器人會在刪除前讀取並處理指令，回覆則透過私訊發送。
- 如需暫時停用，取消勾選「啟用」即可，不必刪除整筆設定。
- 修改後**立即生效**。

## 6. 訊息模板

管理 Discord 機器人回覆使用者時的訊息內容與樣式，支援 Jinja2 模板語法和 Discord Embed 卡片格式。

### 進入方式

**路徑：** Discord > 設定 > 訊息模板

### 欄位說明

| 欄位 | 說明 |
|------|------|
| **名稱** | 模板的辨識名稱 |
| **模板類型** | 此模板用於哪個場景（見下方列表） |
| **啟用** | 是否啟用此模板 |
| **內容 (body)** | 訊息主體文字，支援 Jinja2 語法 |
| **使用 Embed** | 勾選後以 Discord Embed 卡片樣式顯示 |

### Embed 相關欄位（勾選「使用 Embed」後出現）

| 欄位 | 說明 | 範例 |
|------|------|------|
| **Embed 標題** | 卡片的標題文字 | `💳 付款成功` |
| **Embed 色碼** | 卡片左側色條的顏色（Hex 色碼） | `#FF5733` |
| **Embed 圖片網址** | 卡片底部大圖 | `https://example.com/img.png` |
| **Embed 縮圖網址** | 卡片右上角小圖 | `https://example.com/thumb.png` |
| **Embed 頁尾** | 卡片底部小字 | `感謝您的購買！` |

### 模板類型一覽

| 模板類型 | 觸發時機 | 可用變數 |
|----------|----------|----------|
| **已綁定通知** | 用戶重複執行 `!bind` | `{{ points }}` — 目前點數 |
| **綁定成功通知** | 首次綁定成功 | （無） |
| **購買確認** | 用戶執行 `!buy` | `{{ points }}` — 購買點數 |
| **贈送公告** | 贈送時發到公告頻道 | `{{ sender }}`、`{{ receiver }}`、`{{ points }}`、`{{ note }}` |
| **贈送成功通知** | 贈送完成通知贈送者 | `{{ points }}`、`{{ receiver }}`、`{{ remaining_points }}` |
| **付款成功通知** | 付款完成後通知用戶 | `{{ order_no }}`、`{{ points }}`、`{{ amount }}`、`{{ points_before }}`、`{{ points_after }}` |
| **點數查詢** | 用戶執行 `!points` | `{{ points }}` — 目前點數 |
| **群發通知** | 群發的訊息內容 | `{{ message }}`、`{{ role_name }}`、`{{ sender }}`、`{{ guild_name }}` |
| **群發結果通知** | 群發完成後通知發送者 | `{{ role_name }}`、`{{ total }}`、`{{ success }}`、`{{ failed }}` |

### Jinja2 語法快速入門

**插入變數：**
```
目前點數：{{ points }} 點
```

**條件判斷：**
```
{% if note %}備註：{{ note }}{% endif %}
```

**預設值：**
```
備註：{{ note or '無' }}
```

**數字格式化（加千分位逗號）：**
```
金額：NT$ {{ "{:,}".format(amount) }}
```

### 隨機模板功能

同一模板類型可以建立**多個**模板，系統會從已啟用的模板中**隨機選擇**一個使用，讓回覆更有變化。

**範例：** 建立 3 個「綁定成功通知」模板，每次綁定成功時隨機顯示不同的歡迎訊息。

### 注意事項

- 每個模板類型至少要有**一個啟用的模板**，否則機器人會無法回覆。
- 模板語法錯誤時，系統會回退顯示原始模板文字。
- Embed 色碼必須為有效的 Hex 格式（如 `#FF5733`）。
- 修改後**立即生效**。

## 7. 購買訂單管理

查看和追蹤所有用戶的點數購買訂單。

### 進入方式

**路徑：** Discord > 點數 > 購買訂單

### 列表欄位

| 欄位 | 說明 |
|------|------|
| **訂單編號** | 系統自動產生（格式：PT + 時間戳記） |
| **客戶** | 綁定的 Odoo 聯絡人 |
| **Discord ID** | 用戶的 Discord ID |
| **點數** | 購買的點數數量 |
| **金額** | 付款金額（NT$） |
| **付款方式** | 綠界 / 歐富寶 |
| **狀態** | 待付款 / 已付款 / 付款失敗 / 已取消 |
| **建立時間** | 訂單建立的時間 |

### 訂單狀態說明

| 狀態 | 標示顏色 | 說明 |
|------|----------|------|
| **待付款** | 黃色 | 訂單已建立，用戶尚未完成付款 |
| **已付款** | 綠色 | 付款成功，點數已加入帳戶 |
| **付款失敗** | 紅色 | 付款過程中發生錯誤 |
| **已取消** | — | 訂單已取消 |

### 篩選與分組

**快速篩選：**
- 已付款 / 待付款 / 付款失敗
- 綠界 / 歐富寶

**分組檢視：**
- 依狀態分組
- 依付款方式分組
- 依客戶分組

### 注意事項

- 訂單為**唯讀**，無法在後台手動新增或刪除。
- 所有欄位皆為唯讀，訂單狀態由系統自動更新。
- 點擊訂單可查看詳細資訊，包含金流交易編號和付款時間。

## 9. 聯絡人整合

Discord 模組會在 Odoo 聯絡人上新增額外欄位和功能。

### 進入方式

**路徑：** 聯絡人 > 點擊任一聯絡人

### 新增欄位

| 欄位 | 說明 | 可編輯 |
|------|------|--------|
| **Discord ID** | 綁定的 Discord 用戶 ID | 否（唯讀） |
| **點數** | 該用戶的點數餘額 | 是（可手動調整） |

### 智能按鈕

聯絡人表單上方會顯示兩個智能按鈕：

| 按鈕 | 圖示 | 功能 |
|------|------|------|
| **購買訂單** | 購物車 | 點擊後顯示該聯絡人的所有購買訂單 |
| **贈送紀錄** | 禮物 | 點擊後顯示該聯絡人相關的贈送紀錄（包含送出和收到） |

### 手動調整點數

管理員可以直接在聯絡人表單中修改「點數」欄位，用於：

- 客訴處理時手動補點
- 活動獎勵手動發放
- 修正異常資料

> 點數欄位有變更追蹤功能，所有修改都會記錄在聯絡人的 Chatter（討論記錄）中。

### 注意事項

- 每個 Discord 帳號只能綁定**一個**聯絡人，系統有唯一性約束。
- 在聯絡人列表視圖中，也可以選擇顯示 Discord ID 和點數欄位。

# 第二部分：Discord 指令操作

> 此部分為 Discord 使用者的操作指南，說明如何在 Discord 中使用機器人的各項功能。

## 10. 帳號綁定

在使用任何功能之前，您必須先將 Discord 帳號與系統進行綁定。

### 使用方式

在允許的頻道中輸入：

```
!bind
```

### 說明

- 機器人會自動讀取您的 Discord 名稱與頭像，並在系統中建立您的帳號。
- 綁定成功後，機器人會透過**私訊**通知您。
- 每個 Discord 帳號只能綁定一次，重複綁定會提示「已經綁定」並顯示您目前的點數。

### 注意事項

- 請確保您的 Discord **隱私設定**允許接收來自伺服器成員的私訊，否則機器人無法傳送通知給您。
- 綁定後無法自行解除，如需更改請聯繫管理員。

## 11. 查詢點數

隨時查看您目前的點數餘額。

### 使用方式

```
!points
```

### 說明

- 機器人會透過**私訊**回覆您目前的點數餘額。
- 此指令不會在頻道中公開顯示您的點數。

### 注意事項

- 必須先完成帳號綁定才能使用。
- 如果未收到私訊，請檢查您的 Discord 隱私設定。

## 12. 購買點數

透過線上付款購買點數，支援綠界科技（ECPay）及歐富寶（OPay）兩種付款方式。

### 使用方式

```
!buy <點數數量>
```

**範例：**

```
!buy 100
!buy 500
```

### 完整購買流程

1. **發送指令** — 在允許的頻道輸入 `!buy 100`（以購買 100 點為例）。
2. **收到付款連結** — 機器人會透過**私訊**發送一個包含「點擊付款」按鈕的訊息。
3. **點擊付款按鈕** — 點擊後將開啟付款頁面。
4. **選擇付款方式** — 頁面上可選擇「綠界科技」或「歐富寶」。
5. **完成付款** — 依照金流商的指引完成付款程序。
6. **自動到帳** — 付款成功後，點數會**立即自動加入**您的帳戶，同時您會收到一則付款成功的私訊通知。

### 注意事項

- 點數數量必須為**正整數**（如 1、50、100），不接受小數或負數。
- 付款連結為**一次性使用**，付款完成或過期後將自動失效。
- 付款完成後，原本的付款連結訊息會自動刪除。
- 如果付款過程中遇到問題，請勿重複購買，先聯繫管理員確認訂單狀態。
- 實際付款金額 = 點數 × 點數單價（實際單價請以付款頁面顯示為準）。

## 13. 贈送點數

將您的點數贈送給其他已綁定的使用者。

### 使用方式

```
!gift @對方 <點數數量>
!gift @對方 <點數數量> <備註>
```

**範例：**

```
!gift @John 50
!gift @John 100 感謝你的幫助
```

### 說明

- 贈送後，您的點數會立即扣除，對方會立即收到點數。
- 贈送成功後，機器人會透過**私訊**通知您贈送結果及剩餘點數。
- 如果伺服器有設定贈送公告頻道，贈送紀錄會在該頻道公開顯示。

### 注意事項

- **雙方都必須已完成帳號綁定**，否則無法贈送。
- 您的點數餘額必須**大於或等於**贈送數量。
- **不能贈送給自己**。
- 點數數量必須為**正整數**。
- 贈送一旦完成即**無法撤回**，請確認對象和數量後再操作。
- 備註為選填，可用來記錄贈送原因。

## 14. 群發通知

擁有特定身分組的使用者可以向指定身分組的所有成員發送私訊通知。

### 使用方式

```
!announce @身分組 通知內容
```

**範例：**

```
!announce @VIP 今晚 8 點有特別活動，請準時參加！
```

### 說明

- 機器人會逐一私訊該身分組的所有成員（不包含機器人帳號）。
- 發送完成後，您會收到一則結果回報，顯示成功與失敗的數量。

### 注意事項

- 只有被授權的身分組成員才能使用此功能（需在 Odoo 後台設定允許的身分組 ID）。
- 如果目標成員關閉了私訊接收，該成員將無法收到通知，但不影響其他成員。
- 成員數量較多時，發送可能需要一些時間，請耐心等待。
- 請避免頻繁使用此功能，以免造成成員困擾。

## 15. 常見問題 FAQ

### Q：我輸入指令後沒有任何反應？

**可能原因：**

- **尚未綁定帳號** — 請先使用 `!bind` 完成綁定。
- **在錯誤的頻道** — 部分指令可能限制只能在特定頻道使用，請確認您在正確的頻道（管理員可在 Odoo 後台的「頻道設定」中查看）。
- **指令已被停用** — 管理員可能暫時停用了該指令（可在「指令設定」中確認）。
- **指令格式錯誤** — 請確認指令格式正確，例如 `!buy` 後面必須接數字。
- **指令名稱已變更** — 管理員可能自訂了不同的指令名稱。

### Q：我收不到機器人的私訊？

**解決方式：**

1. 開啟 Discord **使用者設定**。
2. 進入「隱私與安全」。
3. 開啟「允許來自伺服器成員的私人訊息」。

### Q：付款成功但點數沒有到帳？

- 通常點數會在付款完成後**立即到帳**。
- 如果超過數分鐘仍未收到，管理員可至 Odoo 後台「購買訂單」中查看該筆訂單的狀態。
- 如為「待付款」狀態，可能是金流回調尚未完成，請確認金流設定是否正確。

### Q：我可以將點數轉回現金嗎？

- 點數**無法**兌換為現金或退款，購買前請確認需求。

### Q：贈送錯對象了怎麼辦？

- 點數贈送一旦完成即**無法撤回**。管理員可在 Odoo 後台手動調整雙方的點數餘額。

### Q：Bot 沒有上線或無回應？

**管理員排查步驟：**

1. 確認 Odoo 設定中的 **Bot Token** 是否正確填寫。
2. 確認 Discord Developer Portal 中已開啟必要的 **Intents**（MESSAGE CONTENT、SERVER MEMBERS）。
3. 嘗試在 Odoo 設定頁面點擊「**重啟 Bot**」按鈕。
4. 檢查 Odoo 伺服器的日誌是否有錯誤訊息。

### Q：付款頁面顯示錯誤或無法選擇付款方式？

**管理員排查步驟：**

1. 確認至少一種金流（綠界或歐富寶）的**商店代號、HashKey、HashIV** 都已正確填寫。
2. 確認**測試模式**的設定與實際環境一致（正式環境請取消勾選）。
3. 確認 Odoo 的 `web.base.url` 系統參數設定正確（付款回調需要用到）。

## 16. 注意事項

### 帳號安全

- 請勿將您的 Discord 帳號借給他人使用，您的帳號與點數直接綁定。
- 如果懷疑帳號被盜用，請立即修改 Discord 密碼並聯繫管理員。

### 付款安全

- 所有付款均透過**綠界科技**或**歐富寶**等第三方合規金流平台處理，您的付款資料不會經過 Discord 機器人。
- 請勿在 Discord 頻道中透露任何付款資訊（如信用卡號等）。

### 頻道訊息自動刪除

- 部分頻道可能設有**訊息自動刪除**功能，您發送的訊息可能在數秒後被自動清除。
- 這是正常現象，不影響指令的執行。機器人的回覆會透過私訊傳送給您。

### 使用規範

- 請勿在短時間內大量重複發送指令，以免觸發速率限制。
- 請遵守伺服器的使用規範，濫用機器人功能可能導致權限被限制。

### 管理員注意事項

- Bot Token、HashKey、HashIV 等敏感資訊請妥善保管，切勿外洩。
- 正式上線前請確認所有金流設定的**測試模式已關閉**。
- 定期檢查「購買訂單」中是否有異常的待付款訂單。
- 建議為機器人指令設定專用頻道，搭配自動刪除功能保持頻道整潔。
